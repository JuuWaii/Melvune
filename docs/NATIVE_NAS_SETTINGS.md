## 2026-09-28 后台任务

新增“后台任务”页，按当前服务器返回值显示任务类型、总数、成功/失败/取消计数及状态。手动刷新不触发再次扫描；任务消失或列表为空不作为扫描成功证据。取消与重试是异步请求，成功提交后仍显示实际回读状态。仅管理员可写，取消和删除需要勾选确认；运行中记录不可删除，仅服务端标记可重试的已结束任务可重试。写入前重新检查任务 ID、类型、创建时间和当前操作条件；删除后检查记录确实消失。接口没有原子条件写入，前置检查不能消除服务端竞态。

接口契约来自当前飞牛前端：task/list 返回数组或 list 包装；写入体为 taskId。拒绝缺失完成标志、非法计数及重复 ID。66 项基础检查通过；113 项窗口回归覆盖运行状态、取消中、失败计数、重试和删除记录。真实只读报告 `.review-audit/tasks-ui/settings-verification.json`（2026-09-28T11:20:37.7035758+00:00）9 项通过，无跳过。真实服务窗口打开任务页及鼠标刷新也通过；未取消、重试或删除用户服务器现有任务。Release 构建 0 警告、0 错误。

## 2026-10-01 设置读取失败隔离

此前素材库、服务器设置、默认访问范围与授权目录依次读取，任一失败会阻止整个设置窗口打开。现在每项独立读取，失败项清除旧快照并在页面提示；有效项继续显示。素材库未知时禁用依赖其列表的默认访问保存和创建入口；服务器快照未知时禁用名称保存；授权目录失败仍允许管理员手动填写 NAS 路径，由原有服务端校验决定是否接受。登录失效与请求取消仍传播到会话/关闭流程，不能作为普通部分失败吞掉。

后台任务保持独立手动刷新，即使其他设置部分失败也可使用。刷新或其他操作返回后仍显示失败项提示，成功重试后清除。管理员角色必须先成功确认；保存时原有来源、角色、旧快照检查与结果回读继续执行。

131 项窗口状态回归全部通过，新增首次打开服务器设置 503、重试恢复、素材库 503 时依赖写入禁用、后台任务保持可用四项检查。Debug/Release 构建零警告、零错误，隐私扫描通过。故障由隔离服务夹具注入，不宣称真实 NAS 网络断连或权限切换已验收；固定 preview.4 包不包含本次改动。

## 2026-10-02 真实隔离目录生命周期

用户提供独立 NAS 测试目录并授权给飞牛音乐后，在该目录下创建唯一 `fnmusic-verify-{32位GUID}` 子目录，分别复制三首歌曲至 original/replacement。两首 FLAC、一首 MP3，六份副本逐一核对 SHA-256 与原文件相同。没有移动或修改原歌曲。

真实服务报告 `.review-audit/library-lifecycle-app/library-lifecycle-verification.json`，时间 `2026-10-02T10:24:47.87561+00:00`，stage=complete、error 为空、16 项检查全部通过。创建和歌词选项修改由第二客户端回读一致；旧设置快照写入被拒绝；歌词选项恢复后再扫描。替换目录预检查完全匹配且不要求额外确认，重关联保留素材库 ID、歌词/元数据选项，第二客户端回读新路径。创建、显式扫描、重关联后扫描均分别取得新的本库 fileScan 任务，每次 total=successCount=3、done=true，失败/取消计数为零。

后台任务读取新增可选 `ext.libraryGUID` 关联，与网页按库显示扫描进度的实际契约一致。判断本库扫描只用源实例、库 ID、任务 ID/创建时间及 fileScan 类型，不用显示名称猜测；缺少关联、任务消失或仅提交成功均不能通过完成检查。取消/重试/删除也重新核对关联，防止相同任务 ID 被改绑至另一个库后继续操作。82 项基础、172 项隔离窗口回归通过，Debug/Release 构建零警告、零错误，隐私扫描通过。

验证器仅在 Debug 中开放 `--verify-native-library-lifecycle`，配置由 `FNMUSIC_LIBRARY_FIXTURE_CONFIG` 指向本机未跟踪 JSON 文件，字段为 OriginalPath、ReplacementPath、FileCount。两个 NAS 路径必须位于同一个唯一测试根的 original/replacement 下，并在授权目录内；现有素材库不能与测试根重叠。准备副本及哈希核对由调用方完成。无匹配或要求确认时停止，不静默同意重关联风险。发现不确定创建结果时只按本次唯一路径和新 ID 恢复清理，不按名称认领资源。现有任务不取消、不重试、不删除。

临时库移除后，全部原素材库与操作前逐字段一致。随后核对原三首歌曲哈希未变，只删除本次创建、文件名和哈希仍匹配的六份副本及空临时目录；清理记录 `.review-audit/library-lifecycle-cleanup.json`。服务端已结束的临时扫描记录留作历史，没有清理其他任务。

本次确认的是 API 生命周期、后台扫描成功计数及双客户端回读；不把它描述为网页鼠标交替操作、窗口交互或每首歌曲 GUID/歌单引用在重关联前后保持的验收。不同权限账号与重启迁移、网页交替编辑及完整交付仍继续验证。固定 preview.6 未覆盖本次改动。
