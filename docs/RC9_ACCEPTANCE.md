# rc.9 安装版验收范围

本轮补齐 Melvune 的 Windows x64 安装 EXE 与 MSI，与 ZIP、便携 EXE 从同一源码提交生成。应用功能继承 rc.8，除版本显示外不改动播放与来源行为，相关历史功能验收见 RC8_ACCEPTANCE.md。

安装器采用独立 Melvune UpgradeCode、产品标识、HKCU 注册表与默认目录，不迁移或卸载改名前应用。普通安装与 ZIP 共用 Melvune.Native 配置，便携使用独立 Data；卸载仅移除安装文件与快捷方式，保留配置。

最终标签构建会执行核心/来源/队列、便携、发布与清理工具检查，并在云端验证 MSI 全部文件、EXE 内嵌 MSI、图标、目录选择和当前用户安装范围；随后实际执行 MSI 自选目录、EXE 默认/自选目录的静默安装及卸载，检查文件摘要、快捷方式和配置保留。任何失败均阻止公开发布。最终结果记录于当前开发清单及云端工作流，包内文档为打包时快照。

未签名状态保持。静默安装不替代各 Windows 版本的图形安装、SmartScreen、权限差异、升级/修复、磁盘/网络路径与硬件测试。用户验证见 RC9_USER_VALIDATION.md。

最终结果：工作流39116856904的构建、独立安装验收和发布全部成功，三组静默安装/卸载及603个载荷/605个MSI文件核对通过；11个发行附件已公开，详情见 [交付回执](RC9_PUBLICATION.md)。包内本文件为封装前快照，当前仓库记录最终结果。
