# 完整播放队列与继续播放

当前Melvune候选在正常退出时保存当前队列。重新打开后显示上次歌曲和进度，保持暂停，点击播放才打开音频。没有当前歌曲时保留其余队列，从右侧队列中双击选择开始。

保存内容包括来源实例与歌曲 ID、显示元数据、队列顺序、当前项、实际播放进度、四种播放模式、显式「下一首播放」安排和最多最近 10000 条回退历史。不同来源的相同歌曲 ID 不合并。随机模式不保存随机数生成器状态，未来随机结果可能不同，上一首和显式下一曲安排保持。

最多 10000 首、文档最多 16 MiB。记录为独立Melvune配置目录中的 playback-resume.json v2；不自动读取改名前的配置目录。保存采用临时文件、原子替换及同目录读写锁（等待上限2秒）；非法、超限或取消的保存不部分覆盖旧文件，损坏的读取不会改写原文件。只保存明确的歌曲显示字段与引用，不保存音频/封面/歌词资源 URL、账号密码或连接令牌。

启动恢复不会覆盖已经创建的新队列；仅在恢复期间调整播放模式时保留上次队列并采用新模式。

来源尚未连接时，歌曲保留在队列中；当前进度保留，点击播放会提示恢复来源。其他来源的曲目仍可选择。重连以原来源身份匹配，不用标题匹配，不替换成另一账号或其他音乐源。来源明确撤销、删除和飞牛退出登录仍按其原有隔离规则停止相关播放；保存的当前待恢复记录不因此错接到其他来源。

停止将当前进度归零并保留队列；移除非当前歌曲不停止当前播放。移除当前歌曲会停止并取消其恢复位置，其余歌曲保留为尚未开始的队列。清空队列停止播放并删除恢复记录，下次启动不会恢复旧队列。普通空队列退出时也保留显式选择的非默认播放模式；清空或移除最后一首仍删除恢复记录。

恢复记录不缓存音频，也不是自动播放或后台下载。强制终止、崩溃、断电及关闭保存失败不保证最后位置。当前交付状态见 RC8_ACCEPTANCE.md；rc.5的历史队列验收保留于RC5_ACCEPTANCE.md。
