# 0.2.0-preview.2 本机验证指南

这是 Windows x64 原生开发测试版，供当前电脑验证，不是正式发布安装包。保留整个目录，双击 `Start-FnMusic.cmd` 启动；也可在 FFmpeg 已位于 PATH 时直接打开 `FnMusic.App.exe`。无需另外安装 .NET，未捆绑 FFmpeg。不要只复制 exe。

## 建议验证顺序

1. 点击“导入文件夹”，通过“浏览文件夹…”选择少量音乐，或输入完整路径。首版支持一个目录及其子目录，最多 10000 首；换目录会替换当前本地库。
2. 检查标题、歌手、时长与搜索；Windows 无法读取的标签回退到文件名，未知时长不能跳转。点击“本地音乐”无需登录 NAS。
3. 双击播放，检查暂停、继续、停止、进度跳转、音量、上一首/下一首和队列模式。先小音量验证。播放格式仍取决于文件及 FFmpeg 解码兼容性。
4. 增加一首音乐后点击“刷新曲库”；重启并再次进入本地音乐，检查目录恢复。
5. 在“连接与账号”连接飞牛并登录，检查曲库、搜索、专辑/歌手、收藏及播放。旧会话升级后可能要求重新登录一次。
6. 如需测试收藏写入，请选可恢复的测试歌曲，完成后恢复原状态。专辑/歌手返回与切页不应改变已建立的播放队列。

## 已知边界

- 这次可验证的是已有飞牛功能与本地音乐，不代表整份路线图完成。
- 多目录分类、跨库歌单、飞牛同步歌单/设置、Emby/Navidrome、自定义源、主题、封面/歌词与对外接口仍待后续。
- 飞牛会话切换仍会重置共享列表和队列。本地扫描跳过链接及无权限子目录，文件移动/改名需重新扫描。
- 首版依赖 Windows 标签读取能力；大规模目录扫描、断网与所有音频格式尚未全面验收。
- 配置仍使用 `%LOCALAPPDATA%/FnMusic.Native/`，与此前原生预览共享。令牌由 DPAPI 保护；本地文件路径只保存在本机配置中。
- 测试目录不包含账号、令牌、音乐文件、调试日志或 FFmpeg。正式分发的依赖许可及安装升级关卡尚未完成，请勿将此本机测试目录作为正式发布包。

反馈时请提供操作步骤、期望/实际结果、格式和错误提示；无需提供密码、令牌或完整私人路径。

## 本轮验证记录

57 项原生检查（含 DPAPI、WAV/FLAC/MP3/OGG 合成解码与跳转）和 41 项窗口状态回归通过；本地 WAV 的时长、播放及暂停跳转已验证。实际鼠标检查了导入对话框、系统目录选择器及取消返回。独立 Release 目录已启动成功，文件 SHA-256 清单位于 `SHA256.json`。

修复了首次发布目录缺少 WinUI XBF/PRI 资源导致的启动崩溃，现由构建目标复制、打包脚本检查。当前结果不代替你的真实 NAS 账户、歌曲和目录验收。
