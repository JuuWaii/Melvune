# 0.2.0-preview.11 本机验证指南

这是 Windows x64 原生测试版。保留整个目录，双击 Start-FnMusic.cmd 或 FnMusic.App.exe 启动。包含 .NET、Windows App SDK 与固定版本的 FFmpeg 解码动态库，无需另装 FFmpeg；不要只复制 exe。

源码工作区可用 `./scripts/check-preview.ps1 -Path ./dist/FnMusic-0.2.0-preview.11-win-x64-verified` 核对包内全部文件哈希、额外文件、程序版本和补丁构建材料；检查旧包需传入对应 -ExpectedVersion，例如旧 preview.10 使用 `-ExpectedVersion 0.2.0-preview.10`。这项检查证明目录完整性，不替代实际运行和分发许可审查。

## 本次重点

- 本地音乐扫描结果按音乐库存为歌曲索引，重启先加载已有曲目并支持直接播放，再后台检查新增、删除和变化；文件大小、修改时间未变时复用元数据。缓存不复制音频，文件在磁盘或网络盘上仍需可访问。后台更新保留播放来源、队列和选中项，失败/取消保留旧索引；损坏或不匹配目录的索引回退到扫描。首次建立索引仍需完成一次扫描。

- 飞牛歌曲/专辑封面、本地封面、飞牛歌词与同名 LRC，播放及跳转时同步高亮。本地 LRC 缺失或不可用时读取受限文件标签；飞牛歌词接口成功返回空内容时，尝试当前播放流中的内嵌歌词，支持定时与纯文本显示。具体标签范围见源码文档 NATIVE_EMBEDDED_LYRICS.md。
- WinUI 黑白主题随系统变化；点击左下角封面进入应用内歌词页，向上覆盖，返回保留原浏览或设置上下文。
- 修复“所有音乐”重置测试窗口尺寸和标题栏底色不一致。
- 播放改用可随机访问的原生解码输入；取消打开、切歌和停止会关闭输入并清理解码器。
- 多个本地音乐库并存，支持命名、分组筛选、刷新和目录重关联；跨库本地歌单支持排序、离线条目保留及单曲重新关联。
- 同级飞牛歌单支持服务器创建/编辑/刷新/播放；管理员可同步素材库选项、服务器名称、默认访问范围，并查看后台任务、重关联目录。
- 系统窗口按钮左侧齿轮进入统一设置，分类连接与账号、外观、播放、音乐库与素材库；外观偏好保存，设置与底部播放器共用音量、静音、模式和设备。
- 返回和音乐搜索移到顶部；左侧重复品牌移除，标题栏名称和图标放大，继续使用 WinUI 黑白主题。从首页、设置或歌单页搜索会进入所有音乐；当前曲库搜索保留范围。
- 所有音乐汇总飞牛与本地，支持来源/本地组/库筛选及跨源搜索；歌曲列表取消分页，挂载完整文本元数据，使用固定行高与容器回收，仅加载可见歌曲封面。飞牛断线仍可浏览本地。两类歌单列于侧栏，右键管理，新建弹层命名，歌曲右键集中播放、收藏、下一首和歌单/歌手/专辑操作。
- 飞牛歌曲、专辑、歌手、歌单及歌词/封面按账号来源缓存到本机；启动、连接、刷新和写入后后台同步，缓存不包含歌曲音频。断线缓存不作为账号当前权限证明。
- 音乐库新建、重关联和扫描确认后在后台完成，支持返回、重新打开管理页和页面外取消；标题栏搜索框右侧显示活动与完成提示，失败或取消保留原结果。首页欢迎语只显示在首页，齿轮紧邻最小化按钮。
- 点击飞牛/本地歌单类别进入各自管理页，支持名称筛选、新建、改名和确认删除；卡片打开详情后返回对应管理页，直接点击侧栏具体歌单仍打开详情。
- 音乐库管理使用卡片及顶部新建/扫描，卡片右侧编辑/删除图标；新建和编辑弹窗按本地/飞牛/其他来源切换字段，其他来源仅保留后续支持说明。歌词播放器列隐藏妨碍队列按钮操作的滚动条。播放队列从右侧滑出，底部播放控件保持可用；歌曲和歌单/队列均支持双击播放。
- JSON 与封面接口从发送到正文读完共用各自的 15 秒期限；关闭客户端取消停滞正文，超时不清除登录且不自动重发，尤其写入超时后应先刷新核对服务器状态。
- 主页面和歌词页共用图标播放栏，喇叭点击静音、音量前有提示图标、队列位于最右；歌词、主导航、队列和命名弹层有过渡动画，并尊重 Windows 动画偏好。本地歌词支持 UTF-8、带 BOM 的 UTF-16/32 及 GB18030/GBK。
- 修复损坏/超限旁置封面阻止后续封面加载、部分 MP3 内嵌封面缺失、刷新后旧封面写回，以及 AIFF/AIF 的 Windows 时长缺失。
- 导入完成后显示完成提示；飞牛设置单项读取失败时，已读取项与后台任务仍可使用，依赖缺失数据的保存禁用。
- 取消本地刷新恢复原列表、选中项和分页；多库扫描完成后统一应用，半途取消不替换部分来源。
- 收藏、浏览/搜索、封面/歌词、飞牛歌单及设置入口按来源能力启用，写入仍保留账号归属、权限和冲突检查。
- 曲目库归属贯通扫描、歌单与播放恢复；旧来源的迟到歌词丢弃，失败后重新打开歌词可重试，保持音频流。
- MP3 准确定位使用固定源码的 500 毫秒预滚补丁；44.1/48 kHz 单/双声道、五种编码四处定位的 80 项内容检查通过，网络读取量仍单独跟踪。
- 强 ETag 绑定后续音频块读取；服务器返回匹配版本时使用 If-Match，版本变化或丢失强标签则拒绝提交旧请求内容。无强标签不声称同样保护。
- 本地 LRC 支持 CR、LF、CRLF 换行；素材库设置冲突后刷新保持原选择，已选库消失时提示重新选择并禁用保存和扫描。

## 建议验证顺序

1. 导入两个少量本地音乐的目录，分别命名和分组，检查标题、歌手、封面、歌词及筛选。每个目录含子目录最多 10000 首；导入新目录保留已有库。确认保存后尝试返回，任务应继续，完成后重新打开管理页可看到新库。带时间标签和纯文本的内嵌歌词都可验证。
   完成一次扫描后退出并重开，进入所有音乐应直接显示已缓存本地歌曲并可播放；后台检查期间尝试搜索、切换页面与播放。在目录中添加或移走一首歌曲，重启后后台完成应更新列表，当前播放保持。网络盘离线时保留旧列表，但音频无法读取时不能播放。
2. 双击播放，检查暂停/恢复、前后跳转、音量与上一首/下一首；尝试较长 WAV、FLAC、MP3、OGG，观察实际声音与歌词是否对齐。
3. 点击左下角封面打开应用内歌词页，调整窗口大小、最大化，再返回所有音乐；窗口尺寸应保持，紧凑布局不应遮挡播放器。点击最右队列图标，检查右侧滑出、双击切歌和点外/Escape 关闭。
4. 使用软件内浅色/深色/跟随系统选项，检查标题栏、播放器、歌词和管理弹窗；重开检查偏好保存。跟随系统时可手动改变 Windows 明暗模式验证通知。
5. 连接飞牛后检查曲库、专辑/歌手、封面、歌词及播放。慢网加载中切换歌曲或停止，旧请求不能恢复旧曲目。
6. 本地播放时退出飞牛会话，本地播放应保持；需要测试收藏写入时使用可恢复的测试歌曲。
7. 从两个本地库各选一首，分别加入同一个本地歌单，调整顺序后播放、重启再打开；缺失文件应保留引用并明确跳过，不能串到其他来源同 ID 曲目。
8. 使用专用飞牛测试歌单，在软件与网页交替修改名称或歌曲后刷新；过期编辑应提示刷新核对。接口无原子版本锁，不承诺并发事务。
9. 管理员在 NAS 隔离测试目录验证素材库创建、选项修改、扫描与后台任务状态。移动测试目录后先检查匹配，再重关联；确认新路径及歌曲索引。不要用真实重要素材库做移除测试。
10. 点击两类歌单类别，检查管理卡片的新建/改名/删除取消、名称筛选及详情返回。检查顶部返回、回车搜索、清空和齿轮点击；保存或模态弹窗打开时不应切换其下的页面。

## 验证边界

- 本版使用准确定位。MP3 首次远距离跳转仍可能扫描较多数据，OGG 部分跳转也有较高读取量；快速近似定位尚未默认启用。不要把本地低延迟视为真实 NAS 慢网保证。
- 当前源码核心 Debug 119 项、Release 内嵌歌词专项 5 项、独立 FFmpeg 六格式 12 文件、原生内嵌专项 65 项及最终完整窗口 610 项通过；不同报告的范围分别见 NATIVE_EMBEDDED_LYRICS.md、NATIVE_BACKGROUND_LIBRARY.md、NATIVE_COVER_RELIABILITY.md。新编辑器与跨库歌单实际输入路径、分组、右键加入、顺序调整、连续播放及独立重启已验证，见 NATIVE_LOCAL_FLOW_ACCEPTANCE.md；系统文件夹选择器最终确认仍受工具目标窗口限制。最终窗口回归还覆盖命名弹窗打开时齿轮、返回和搜索不能切换背后的页面。本版发布文件仍需单独完成启动与依赖核验，不能直接继承旧包的实际操作报告。真实 NAS 隔离目录生命周期、歌单/服务器名称/素材库选项的网页交替编辑、重关联歌曲 GUID/音频哈希及歌单引用已通过对应阶段检查。最新重关联任务完成计数未捕获，完整增强探针仍未通过，不把记录消失作为成功。生成音频十种格式、MP3/FLAC/M4A 内嵌 PNG、满容量目录扫描、96 组歌词文件及 80 项定位内容检查已有阶段验收；不代表全部编码变体。
- 两个权限账号的正式视图模型切换与独立进程恢复已经验证，但完整登录键鼠和不同权限设置界面仍需验收；更多 DPI、系统主题通知、网络异常/连续交互矩阵、正式安装升级及完整分发材料审查保留。应用内歌词、侧栏歌单、右键菜单、管理全屏页与右侧队列以及统一设置已接入，详见 UI_REORGANIZATION.md 与 BUG_TRIAGE_2026_10_04.md。Emby/Navidrome、自定义源、桌面歌词及通用信息接口保留后续。本版不代表全部重点验收或所有历史需求完成。
- 本地标签优先读取 Windows；时长缺失时通过受限 FFmpeg 流探测回退，缺失标题仍显示文件名。旁置封面无效时继续尝试下一候选，Windows 缩略图无图片时可读取 FFmpeg 内嵌封面。本地扫描跳过链接和无权限目录，文件移动后需刷新。
- 配置保存在 %LOCALAPPDATA%/FnMusic.Native/，与旧原生预览共用；令牌由 DPAPI 保护。测试目录不含账号、令牌、私人歌曲或调试报告。
- 本地歌单读取兼容第 1 版；本版保存歌单后升级为第 2 版，以保留多个音乐库归属。旧客户端（含 preview.5）无法读取第 2 版。若需对比旧版，保存前自行备份 local-playlists.json，并避免两版交替保存同一配置；其他库和会话格式不变。
- 依赖版本及许可见 NATIVE_DECODER_DEPENDENCIES.md 和 licenses/；文件校验见 SHA256.json。当前仅供本机验证，尚未完成正式安装升级和对外分发材料审查。
