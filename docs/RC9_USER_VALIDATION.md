# rc.9 用户验证单

安装 EXE 与 MSI 选择一种即可。两者默认按当前用户安装到 `%LOCALAPPDATA%\Programs\Melvune`，支持可写目录选择。EXE 点击 Options / Browse，MSI 使用中文目录选择页。应用显示版本为 0.2.0-rc.9，Windows Installer 内部版本为 0.2.1009。

- EXE 和 MSI：确认图标与版本正确，自选含中文、空格的可写目录安装；从开始菜单打开并正常播放。
- Windows 应用设置或原安装包卸载后，安装文件和快捷方式应移除，Melvune.Native 配置保留。
- 已安装的同版可进入修复或卸载；当前没有旧品牌安装器升级兼容，旧版不会被替换。
- ZIP、安装版共用普通配置，不同时运行并写入相同配置；便携 EXE 的 Data 配置独立。
- 在未签名提示、权限变化、目录不可写、网络位置、重启要求等情况下核对提示，不将云端静默安装视为这些场景已完成验收。

播放、歌词、桌面联动与真实服务器的详细验证项目继续参考 RC8_USER_VALIDATION.md。反馈请注明安装入口、系统版本、选择目录的特征、步骤、预期/实际，日志和截图需脱敏。
