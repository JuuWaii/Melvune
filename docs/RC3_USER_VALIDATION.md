# 0.2.0-rc.3 用户集中验证单

使用当前开发清单列出的同一 rc.3 ZIP 或便携 EXE；不要用历史安装器替代。先正常退出旧客户端并备份个人配置，再将新版本放到独立目录。候选版未签名，不自动更新、迁移或清理旧包。以下按功能组集中检查，记录失败项即可。

| 检查组 | 操作与通过标准 |
| --- | --- |
| 启动与升级 | ZIP 保持完整目录后运行 `Start-FnMusic.cmd`；便携 EXE 放在可写目录运行。核对版本为 `0.2.0-rc.3`，旧配置、连接与本地歌单可读取。ZIP 默认配置与便携 `FnMusic-portable\Data` 独立，不应自动互相迁移。需要回退时退出新版本，再使用旧包与对应配置备份。 |
| 播放与关闭后续播 | 本地和飞牛各播放一首，检查暂停、切歌、定位、静音、队列与歌词。播放到中途正常退出，重启应显示上次歌曲和进度且保持暂停；点击播放继续。暂停退出也保留进度；来源离线时保留记录，恢复后可继续。显式停止归零，清空队列或移除当前歌曲取消恢复。此项只保存当前一首，强制终止、崩溃和断电不保证最后位置。 |
| 音乐库与歌单 | 本地索引首次完成后重启应先显示缓存，再后台刷新；离线库保留记录。新建混合本地与已接入远端来源的本地歌单，重启后顺序和身份保持。飞牛歌单在网页修改后显式刷新；管理员素材库操作只用独立测试目录，任务消失不能当作完成。 |
| 真实第三方服务 | 对实际使用的 Navidrome、Emby 或 Subsonic 连接分别检查授权目录、曲名/歌手/专辑搜索、原始播放及远距离定位、封面和可用歌词；未提供歌词接口时检查可用内嵌歌词回退。Subsonic 按专辑目录读取，最多 10,000 首，不保证未归专辑歌曲；Emby 同样最多 10,000 首。核对代理子路径、版本和 Range 支持。断网刷新保留此前目录，账号权限撤销只影响该来源；飞牛注销不影响独立来源。编辑改名、密码留空、重新认证及删除取消/确认分别检查；删除后本地歌单引用仍保留为不可用。保存或删除已成功时，后续刷新失败应单独提示，不能否认已提交结果。 |
| Windows 主题与输出设备 | 浅色、深色和跟随系统分别切换，核对播放按钮、文字和普通图标对比度；只有主操作与选中背景使用强调色。耳机/音箱切换、Windows 默认设备变更及 USB/蓝牙拔插后检查列表、回退提示、暂停状态、队列与实际声音；重新接入设备不应自动抢回输出。真实硬件无声隙恢复不在统一保证范围。 |
| 桌面联动 | 主界面与应用内歌词页「词」按钮都能显示/隐藏透明歌词；右键设置、锁定穿透和托盘解锁可用。开启关闭到托盘后关窗口应继续播放，从托盘退出才保存并退出。SMTC 开关、固定全局快捷键及睡眠定时分别检查；计时到期只停止一次，重启不恢复定时。系统媒体卡片的实际样式和实体键行为需在当前 Windows 环境检查。 |
| 只读信息接口 | 需要时启用接口，使用包内 `examples/InfoClient` 查看歌曲、实际状态和歌词；切歌后更新，关闭接口后无法连接。本接口需第三方按协议接入，开关不等于自动兼容其他音乐软件。 |

反馈请记录：版本、入口、服务类型/版本或设备型号、复现步骤、预期与实际行为，以及已脱敏错误提示。不要发送密码、令牌、私人目录或未经脱敏的服务日志。真实服务、硬件、输入法、多显示器和 DPI 结果与受控自动检查分开记录；当前证据见仓库 `docs/RC3_ACCEPTANCE.md`。
