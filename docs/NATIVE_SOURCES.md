# 音乐源身份阶段记录

更新：2026-09-22。

正式飞牛登录使用规范化服务器作用域与本次提交的登录账号生成 SHA-256 映射键，本机 `sources.json` 保存映射键到随机 UUID 的关系。重启或退出后重新登录相同账号会复用来源 ID；不同服务器或账号分别分配。账号仅去除首尾空白，不擅自忽略大小写。此摘要不是凭据加密或匿名化机制，令牌仍由 DPAPI 单独保护。

当前没有已验证的服务端不可变用户 ID，不能以显示名替代。因此账号改名、登录别名或大小写变化可能产生新来源，后续应核对稳定用户标识并提供显式迁移，不能自动按曲名合并。

连接设置保存 `SourceAccountKey`。登录时先清除旧令牌，再保存账户归属，最后保存新令牌，避免中途退出把新令牌关联到旧来源。旧设置缺少账户归属时保留连接设置并提示重新登录一次，不根据当前显示名猜测。退出登录保留来源映射，为以后本地歌单保留引用。

读取映射时校验格式、大小、空 ID 与重复 ID；异常不静默重建。独占文件锁避免多进程覆盖，冲突时操作失败并允许重试；临时文件写完后替换正式文件。映射暂不提供删除/编辑界面。

正式认证发布前创建绑定不可变来源 ID 的客户端实例，曲库、搜索、收藏及专辑/歌手歌曲共用解析入口。窗口播放与收藏写入使用 `TrackReference`，来源不符时在网络请求前拒绝。原始 ID 重载仍供单源底层调用和显式验证工具使用，合成测试可使用空来源 ID。未来跨源持久化歌单必须拒绝空来源 ID。

验证：43 项原生检查通过，新增覆盖映射跨实例恢复、服务器/账号隔离、连接设置回读、损坏与取消保护、四类读取的来源标记以及跨来源播放/收藏拒绝；Release 构建零警告零错误，隐私扫描通过。未操作真实 NAS 账户，真实重启恢复、切换账户和旧设置迁移界面尚待验收。

## 统一播放路由

`IMusicPlaybackSource` 提供来源描述和音频流入口，`MusicPlaybackRouter` 按来源 UUID 精确选择已注册实例，并校验播放能力。未知来源或不支持播放时明确失败，不回退到当前飞牛账户。空 ID 与重复注册被拒绝，重新登录须先注销旧实例。

正式飞牛登录注册 `NasPlaybackSource`；更改连接、重新登录、退出、会话失效及窗口关闭时注销对应实例。注销会取消该来源正在加载的请求，不影响其他注册来源。即使 Provider 忽略取消，迟到返回的流也会被释放；旧实例的迟到失效错误不能让同 ID 的新实例退出登录。成功返回的流由播放器负责释放，注销不代替播放器停止当前已打开的流。

窗口通过统一路由打开音频。来源不可用时停止旧音频并明确提示，防止队列已经选到新歌曲却仍播放上一首。来源失效只针对匹配的飞牛账户触发退出流程。

48 项原生检查通过，新增覆盖两个来源共享曲目 ID 的准确路由、未知来源/能力不足、重复注册、注销再注册、迟到流释放、旧实例失效隔离及调用方取消；Debug/Release 构建均零警告零错误。34 项合成窗口状态回归通过（合成播放绕过网络 Provider，不能替代真实路由验收），隐私扫描通过。真实 NAS 账户登录迁移仍未实测。

正式界面目前接入当前飞牛来源及多个本地目录来源，支持命名/分组、跨库本地歌单与混合队列，见 [多目录阶段](NATIVE_MULTI_LIBRARIES.md)。第三方适配仍在后续节点。

## 2026-10-01：来源能力与曲目入口

## 2026-10-01：浏览与同步管理入口

侧栏与浏览页的飞牛歌曲、专辑、歌手、收藏、歌单和设置入口按当前注册来源的读取能力启用；没有登录或不支持时提供禁用原因。搜索按来源搜索能力启用，本地搜索不依赖飞牛连接。直接调用浏览或搜索方法也会检查能力，不清空或切换原页面。正式会话发布和注销发送 AuthenticatedClient 通知，窗口同步更新入口，关闭窗口时解除订阅。

飞牛歌单按读取/写入能力分别处理：只读时保留选择、刷新和可播放条目，禁用创建、改名、删除及增删歌曲；提交函数在执行前再次检查读写能力。设置、素材库、后台任务和重关联写入同时要求读写能力与服务端管理员身份，读取/刷新独立保留。能力没有替代原有字段快照、冲突、确认、权限或来源检查。

## 2026-10-01：曲目库归属与歌单快照

MusicTrack 新增独立于 TrackReference 的多个库 ID，LibraryReference 同时包含源实例 ID 与库 ID；相同库 ID 在不同来源下不相同，改变库归属不改变队列去重或曲目身份。本地目录 Provider 暴露所属 MusicLibrary，扫描曲目保存该目录的稳定库 ID；刷新和根路径重关联继续使用原 SourceId，因此库引用保持。
