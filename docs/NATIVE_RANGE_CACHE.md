# 强版本流的近期块缓存

2026-10-08。OGG准确定位会在头部、尾部和多个探测区间间往返，原单块缓存反复下载相同范围。新诊断记录第一轮实际Range起点及次数：OGG头部出现四次完整块响应（另有一字节长度探测），尾块三次、部分定位块两至三次。复用这些经过验证的字节，不改变解码器定位策略。

## 实现与边界

`HttpRangeStream` 对打开时具有强ETag的流，保留最多八个256 KiB近期块，按最近读取顺序淘汰，缓存有效载荷上限2 MiB；单次正在读取的新块仍可能额外占256 KiB。所有新块仍携带If-Match，核对206、区间、长度和相同强版本，完整读取并复核取消/关闭后才发布或淘汰旧块。命中缓存不请求网络，使用此前已验证的同一文件版本。

弱ETag或没有版本标识的流保持原单块行为；不将服务器未声明的版本一致性当作保证。缓存属于当前流，关闭时在持有读取锁的路径清空；关闭不会为清空缓存等待正在执行的原生IO。没有磁盘缓存、提前预取、快速定位或新的外部协议。

## 回归与测量

新增强版本近期块/淘汰测试在原实现中真实失败；修改后通过。检查包括热块在第九块加入后保持、最旧块重新请求、跨块读取及短尾块/EOF；取消或版本变化不得发布新块、淘汰旧块或改变目标缓冲/位置，重试必须重新请求；已取消的缓存命中及关闭后读取拒绝，弱/无标签仍单块。
