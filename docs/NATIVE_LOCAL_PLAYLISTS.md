# 本地歌单

2026-09-26：侧栏“本地歌单”提供创建、改名、删除、添加当前歌曲、移除、上下排序和播放。每次编辑保存至本机 local-playlists.json；不会修改远端歌单或音乐文件。

先在曲目列表选中歌曲，再打开歌单，选择目标歌单并加入。来自不同已接入来源的歌曲以来源实例＋曲目 ID 区分，保存显示信息及封面标识。离线和缺失条目保留并标注，播放时跳过不可用项。新版本冲突会重新读取并提示重试；损坏文件不覆盖。删除需要勾选明确确认。

验证：59 项基础检查和 79 项真实窗口控件状态检查通过；新增窗口检查调用按钮自动化接口，覆盖创建、改名、排序、移除、重复加入、删除仅影响歌单、离线项禁播及保留、歌单播放的歌词和封面。测试使用独立 synthetic-settings，不修改用户歌单。尚未将多目录重启恢复、远端实际跨源连续播放及大歌单交互标为完成。

## 2026-09-27：条目重新关联

本地歌单新增“将所选条目重新关联到列表歌曲”。先在音乐库中选中新位置/新文件名的歌曲，再打开歌单选择失效条目并重新关联；替换引用及显示快照，保留条目 ID 与顺序。如果目标歌曲已在同一歌单中，提示处理重复条目并拒绝覆盖。列表显示素材来源/本地库分组，操作区展示目标歌曲。此功能逐条操作，不根据同名歌曲猜测关联，也不自动批量改动其他歌单。

108 项窗口检查通过，新增重新关联后的稳定条目身份和可播放状态；其余歌单创建、排序、保存和离线保留回归仍通过。

## 2026-10-01：音乐库归属保存
