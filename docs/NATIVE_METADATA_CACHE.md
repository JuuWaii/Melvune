# 飞牛资料缓存与后台同步

日期：2026-10-05。对应 `bug/2026_10_5.md` 的资料缓存反馈。本阶段不代表本地音乐库扫描导航和内嵌歌词已完成。

## 行为

- 连接成功、恢复已记住的账号及点击曲库/歌单刷新时启动后台同步。收藏和歌单写入后也触发更新；连续请求合并为一次后续同步。
- 标题栏搜索操作右侧显示活动环，提示包含当前阶段和进度；完成、部分封面/歌词失败或同步失败分别提示，提示八秒后收起。同步不锁定浏览导航，不把首页或其他页面跳回曲库。
- 保存完整歌曲信息、收藏、专辑/歌手详情与成员、歌手关联专辑、飞牛歌单与成员，以及歌曲的首选歌词和歌曲/专辑/歌手/歌单封面。不保存音频、会话或密码。缓存范围为当前客户端 API 模型支持的资料，不等同于服务端数据库备份，也不包含全部歌词候选版本或未建模的标签。
- 所有音乐、收藏、专辑/歌手及详情、歌手关联专辑、歌单管理和歌单详情使用当前账号的快照；封面和歌词使用持久化资料，不存在时按需请求。歌单编辑的冲突检查和写后回读继续直接请求服务器。
- 资料位于应用配置目录的 `nas-metadata/<来源 GUID>/`。来源注册表既有的服务器与账号隔离仍适用；封面和歌词文件名由标识哈希构成，标识中的路径字符不会进入文件路径。
- 启动时先确认账号可以浏览再加载同来源缓存，后台再刷新完整目录；当前返回空目录时不启用旧目录，并以新的空快照覆盖。切换账号、会话撤销、关闭会取消旧任务；迟到结果不能更改新账号快照、活动环或提示。
- 目录校验通过后原子替换；读取损坏、未知版本或跨来源文档时忽略。目录同步失败保留原快照；单项封面/歌词失败保留原资料并汇总待重试数量。缓存大封面优先于旧缩略图；解码失败的封面移除后允许重试。

## 边界

- 目录文档最多 64 MiB，歌曲/专辑/歌手各最多 100000 项，歌单最多 10000 项，累计成员及关联条目最多 1000000；单张封面最多 4 MiB，歌词文档最多 2 MiB。超限或目录分页不一致不会提交部分目录。这些是条目及单文件限制，并非整个磁盘缓存的容量配额。
- 所有文本目录完成后即可使用，封面和歌词继续以两个请求并发更新。首次同步大型资料库可能耗时；活动环不代表音频下载。历史不再引用的资料文件尚未自动回收，缓存占用管理保留后续。
- 本阶段维持既有登录条件，尚不提供断网启动后完全离线浏览或播放飞牛音频。相同账号的旧快照在新同步完成前可能短暂显示旧资料；在线权限探测和空目录处理不能替代服务端对逐首播放及写入的授权。
- 音乐库管理中的扫描/保存导航分离，以及本地文件内嵌歌词解析，按反馈队列继续处理。
