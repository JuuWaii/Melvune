## 批次与检查规则

1. **整理批次 D01–D03**：本轮完成文档收敛，不因文档改动重跑完整窗口/格式/网络测试。
2. **开发批次 D04–D07**：集中修复与分发收尾。新缺陷只补能重现问题、保护行为的针对性回归；不每改一项就构建/全套检查/生成新包。
3. **统一检查与产物批次 D08–D10**：先统一构建和回归，修复实际失败，再生成一个候选包并验收。只因新改动或失败重跑相关检查；不要反复发布多个仅指南不同的包。
4. **交付批次 D11–D12**：更新状态、交付唯一产物和集中反馈单。用户验证中的非阻断体验问题移入后续版本；崩溃、无法播放、数据/账号隔离错误必须先修复。

日常汇报使用“当前批次 / 本批已完成 / 剩余阻断 / 下一步”，批次完成或出现实际阻断时给出结果。工具长时间执行时简短说明状态，不反复堆叠历史通过数量。每批形成范围明确的本地提交；不混入用户 bug 文件改名、img、会话、测试副本及构建产物。

## 明确推迟到后续版本

- Navidrome、Emby、自定义通用音乐源及更多账户连接方式；首版只承诺当前飞牛和本地来源。
- 桌面歌词、对外歌词/音乐信息 API、SMTC/媒体键、托盘、全局快捷键、睡眠定时和设备热插拔完善。
- FN Connect、OAuth、HLS/CUE 扩展、MP3 大读取量优化、更多编码/采样率/声道矩阵与长期压力测试。
- 更多输入法、触摸操作、持续快速拖动、超大真实 NAS 网络容量和更多 DPI 组合的全面验收。
- 重关联扫描消失记录的历史完成计数追查；当前必须保留未确认提示、引用保护，不以消失记录冒充成功。
- 安装器、自动更新、应用商店和签名发行；本版提供可独立运行的完整便携目录。来源/配置迁移基础保护不能随之推迟。
- 新一轮纯视觉设计和已经解决的布局问题。

这些项目从本次发布阻断队列移出，保留在旧路线图作为后续需求。许可、凭据保护、数据不丢失、当前来源的正常播放和最终包可运行不允许延期。
