# 压缩音频持续 Range 定位与释放

2026-10-08。MP3、OGG 各 60 轮正式 Range 输入、连续定位、实际播放推进及停止释放，共 120 轮、367 项条件通过。此前 SeekProbe 的 60 轮打开压力检查使用本地文件流；本次补齐全程 `HttpRangeStream`，没有把旧本地流检查当作网络输入检查。

## 方法

独立生成两段 10 分钟、48 kHz 双声道粉红噪声，固定噪声种子；MP3 为 192 kbps CBR，OGG 为 Vorbis q6。文件分别为 14,401,196 与 10,812,447 字节，均超过 5 MiB，不沿用此前约 1.95 MB 的恒定音调 OGG 样本。

每轮创建新的正式 Range 流、专用 HttpClient 和受控处理器，后者只接受保留测试域名及显式字节范围，返回强 ETag 并实际要求后续 If-Match。使用链接生产源码的 `NativeMusicPlayer` 与 `SeekablePlayback`，默认准确定位和固定预滚解码器；不启用快速定位或实验读取缓冲。

等待 MediaOpened 后依次设置 500、20、300、100 秒，每次间隔 25 毫秒，最后必须进入 Playing 并越过 100.25 秒、未超过 105 秒。停止后等待正式 PendingCleanup、确认 Source 已释放，记录累计 Range 响应字节、请求数、整轮耗时及进程私有内存。每种格式第20轮后至结束的内存增长不得超过96 MiB；每轮读取请求/字节有异常循环保护上限。结束核对生成音频 SHA-256，按精确自有路径清理。
