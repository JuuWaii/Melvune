# 所有音乐完整列表

2026-10-05 手动反馈：273 首每页 50 首，共六页，第六页的“下一页”按旧逻辑禁用。按用户要求取消所有音乐分页，而不是增加空页。完整列表覆盖全部来源、飞牛来源和本地来源；收藏及专辑/歌手详情原分页暂不改变。

## 实现

- `TrackCatalogReader` 逐页读取歌曲文本元数据并构建完整快照，不下载音频；每页 50 首，最多 100000 首。总数变化、缺失行、重复来源引用或超限均拒绝，不把不完整结果发布为完整目录。调用取消后不发起后续页。
- 飞牛完整快照与筛选后的本地曲目合并后一次挂载到 ListView；页码固定为内部兼容值 1，隐藏上一页/下一页，状态显示真实完整数量。刷新保留仍存在的选曲；搜索、来源/分组/库筛选、跨源同 ID、会话清理和取消保护保持。双击和右键播放从当前完整列表建立固定队列。
- 歌曲容器固定 64 DIP，保留 ListView 的 ItemsStackPanel 回收；位于 Grid 的有限高度行中，避免外层无限高度 ScrollViewer 破坏虚拟化。依照 [微软 ListView 性能说明](https://learn.microsoft.com/en-us/windows/apps/develop/performance/optimize-gridview-and-listview)。
- 共用歌曲行的封面使用 [EffectiveViewportChanged](https://learn.microsoft.com/en-us/windows/windows-app-sdk/api/winrt/microsoft.ui.xaml.frameworkelement.effectiveviewportchanged) 判断与实际可见区域的交集；进入视野后请求，离开或回收时取消并清空原图。既有四路限流、封面缓存、占位及迟到结果隔离继续生效。底部/全屏封面加载不受歌曲行限制。
