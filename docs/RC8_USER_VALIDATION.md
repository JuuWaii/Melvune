# Melvune rc.8 使用与验证

本轮目标为 Melvune 0.2.0-rc.8 Windows x64 ZIP 和便携 EXE。实际产物与集中验证结果以 [当前开发清单](NEXT_DEVELOPMENT_CHECKLIST.md) 及 [rc.8 验收记录](RC8_ACCEPTANCE.md) 为准；源码和用户验证单的存在不代表已经发布。

ZIP 解压后运行 `Start-Melvune.cmd` 或 `Melvune.App.exe`，保留全部依赖文件。便携 EXE 放在可写目录运行，会创建同级 `Melvune-portable`，其中 `Data` 保存便携配置。候选版未签名，完整 MSI/EXE 安装器、自动更新和正式发布后置。

本轮按独立新项目整理源码、程序集、资源、解码器构建材料与便携格式，不自动读取、迁移或复用旧品牌配置、凭据、歌单和协议。ZIP 默认使用 `%LOCALAPPDATA%\Melvune.Native`；首次使用需重新添加音乐源。旧目录和历史发布包保留原样，旧版本仍按原入口使用；不要用新包覆盖旧包。

1. 从 ZIP 和便携 EXE 分别启动，确认标题、托盘、文件属性、桌面歌词及错误提示使用 Melvune，图标正常；缺少依赖时不应出现静默失败。
2. 在新配置中添加本地音乐库，确认扫描、缓存重启读取、封面、歌词、双击播放和拖动进度可用。关闭后重启，点击播放可从保留的歌曲进度继续。
3. 添加飞牛或其他音乐源，检查音乐库、收藏和歌单。飞牛音乐仍是来源名称；“飞牛歌单单独分组”打开后分类显示，关闭后合并，音乐管理始终位于侧栏底部。
4. 检查浅色/深色主题、强调按钮可读性、底部播放栏、应用内歌词展开动画和右侧播放队列；队列及侧栏滚动条不应遮住按钮。
5. 检查 SMTC、桌面歌词快捷按钮、透明背景、锁定穿透以及应用中解锁；新“允许本机应用读取播放信息与歌词”接口保持独立，使用随包 `Melvune.InfoClient.exe` 验证。
6. 首次关闭选择收起托盘或退出，记住选择后再次关闭行为应一致。退出前记录测试源、播放进度和界面设置，重启后核对新配置的持久化。

真实听音、媒体按键、更多硬件/DPI和第三方服务部署若未实测，应记录为未验证；自动化通过不能替代这些检查。
