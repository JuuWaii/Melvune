# rc.7 使用与验证

ZIP解压运行 FnMusic.App.exe，或使用便携EXE；旧包保留，未签名候选版。

1. 连接飞牛后，默认关闭“飞牛歌单单独分组”，飞牛歌单与其他歌单合并显示。打开“音乐管理 → 歌单”或“设置 → 外观”开启此项，侧栏出现飞牛歌单/其他歌单两组；关闭重新合并，任何模式均不隐藏飞牛歌单。旧版开关的开/关值分别迁移为分组/合并。
2. 飞牛歌单条目使用黑白官方标志作为淡背景，不再显示彩色前景图标；原图不改绘，浅色和深色主题均应清晰可读。
3. 音乐管理固定在侧栏最下方、播放栏上方。用长歌单列表和窄窗口检查入口不会随列表滚走；歌词页面返回布局应保持。
4. 导入或重扫本地库时，后台最多四路读取元数据，界面可继续操作或取消。取消后原索引保留，完成后的歌曲排序确定，未变化文件复用缓存。
5. 正常退出后再启动，分组偏好、歌单、队列及播放进度应保持。记住关闭选择后不再询问。

并发不是固定帧数或线性加速保证。更多硬件/DPI、真实听音及第三方部署兼容仍待验证；不提供第三方服务写入、签名或完整安装器。
