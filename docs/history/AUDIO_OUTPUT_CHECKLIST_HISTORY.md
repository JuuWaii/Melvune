## 分工与边界

- 主代理负责播放器与 UI 集成、集中回归、修复及交付；子代理分别负责原生设备监听和只读审查。
- 不修改 Windows 的默认设备设置。设备选择只作用于本应用；不将模拟通知和枚举夹具当作实际硬件拔插。
- 真实 USB/蓝牙插拔、驱动异常、全部设备断开与多显示器/DPI 仍需用户硬件验收；不承诺切换无声隙。
- 托盘收起期间监听继续；明确退出时使在途请求失效并停止监听。
- 第三方音乐源、自定义快捷键、自动更新、签名/商店/稳定版、完整安装器和新视觉改版继续延期。本轮完成后以实际反馈优先，不反复扩大检查矩阵。
