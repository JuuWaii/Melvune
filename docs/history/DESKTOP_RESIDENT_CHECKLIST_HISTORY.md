## 本轮范围与优先级

1. **P0：系统托盘与歌词解锁**。托盘显示/恢复主窗口、播放控制、显示/隐藏桌面歌词、解锁并找回歌词、明确退出；锁定歌词后不必进入设置才能恢复操作。
2. **P0：可选关闭到托盘**。默认保持原有关闭即退出；用户启用且托盘成功创建后，点窗口关闭只隐藏主窗口，播放和歌词继续。托盘退出始终真正退出；托盘创建失败时不得隐藏而无法找回。
3. **P1：可选全局快捷键**。默认关闭；开启后固定组合控制播放/暂停、上一首、下一首、歌词显示、歌词解锁。冲突明确提示，可用组合继续工作，关闭和退出释放占用。自定义键位留待以后。
4. **P1：睡眠定时**。15/30/60/90 分钟后停止播放，可取消或替换；显示剩余时间。暂停、切歌、隐藏主窗口不丢失倒计时；到期只停止一次，重启不恢复旧定时。不关闭 Windows 或修改系统电源。

## 并行分工与检查规则

- 主代理：设置、主窗口/播放链路、关闭生命周期、睡眠定时 UI、清单和最终交付。
- 子代理 A：原生托盘服务与托盘命令；独立文件，不能改共享主窗口。
- 子代理 B：原生全局快捷键服务与相关验证；独立文件。
- 子代理 C：定时核心模型及有意义的到期/替换回归；不改主窗口。
- 使用一套命令契约，复用当前播放器。开发阶段不逐控件构建或重跑全套；S02–S05 合并后集中检查一次，依据失败补测。
