# FNMusic 当前长任务：自定义 HTTP/JSON 音乐源与 rc.4 交付

更新：2026-10-15。本轮以 J01–J06 为唯一开发清单，完成一组功能后统一构建、回归和修复。rc.3 已交付记录保留在 [历史清单](RC3_CHECKLIST_HISTORY.md) 与 [rc.3 验收](RC3_ACCEPTANCE.md)。

目标：新增匿名、同源、只读的自定义 HTTP/JSON 音乐源，接入现有音乐库、播放、封面、歌词、跨库本地歌单和关闭后续播；交付统一 `0.2.0-rc.4` Windows x64 ZIP 与便携 EXE。保留旧包和用户改动，本轮只作本地交付，不推送、打标签或上传 Release。

匿名源首版最多 10000 首。通过已知字段映射接入 JSON 列表，不执行脚本，不使用账号密码、Cookie、自定义认证头、签名参数或跨域 CDN；媒体地址必须同源且不带查询参数。修改服务地址或字段方案需新建音乐库，防止同一歌曲 ID 指向另一份媒体。详细配置见 [HTTP/JSON 来源](HTTP_JSON_SOURCES.md)。

本轮继承 rc.3 的飞牛/本地音乐、Navidrome/Emby/Subsonic 只读来源、两类歌单、封面/歌词/右侧队列、黑白主题、桌面歌词、托盘、SMTC、全局快捷键、睡眠定时、设备监视与本机只读信息接口。正常退出保存当前一首及实际进度，重启保持暂停；完整队列持久化后置。

已交付 [rc.4 ZIP](../dist/FnMusic-0.2.0-rc.4-win-x64.zip) 与 [便携 EXE](../dist/FnMusic-0.2.0-rc.4-win-x64-portable/FnMusic-0.2.0-rc.4-win-x64-portable.exe)，二选一即可。来源修订 `835c8db00a34402d0efbc0b7e62eeabefc944932`；核心 120 项、窗口 1022 项及协议/存储/发布材料检查通过，最终包 600 文件摘要/CRC 与实际启动、关闭、匿名播放、封面/歌词和继续播放已验。具体大小、SHA-256 和证据见 [rc.4 验收记录](RC4_ACCEPTANCE.md)。此前 rc.3 及更早包继续保留。

集中反馈按 [rc.4 用户验证单](RC4_USER_VALIDATION.md) 进行。受控协议与窗口测试不能代表真实服务器、实际听音、硬件、全部 DPI/编码组合已验收。认证式自定义源、脚本转换、跨域 CDN、第三方服务端写入、转码、完整队列恢复、自动更新、签名和完整安装器均后置。
