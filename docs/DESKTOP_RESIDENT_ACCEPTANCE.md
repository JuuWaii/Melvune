# 桌面常驻增强批次验收

日期：2026-10-12。本轮按 [统一开发清单](NEXT_DEVELOPMENT_CHECKLIST.md) 实现托盘/歌词解锁、可选关闭到托盘、可选全局快捷键和睡眠定时；继续使用 rc.2，独立批次目录区分修订。

## 实现与默认值

- 原生系统托盘默认开启；菜单提供打开主窗口、播放/暂停、上下首、歌词显示/隐藏、锁定后的解锁找回和真正退出。提示不包含歌曲、服务或账号私有数据。
- 关闭到托盘默认关闭；仅托盘已启用且创建成功时允许隐藏。失去托盘时恢复主窗口；菜单退出不受关闭偏好影响，清理歌词、媒体会话、只读接口和快捷键。
- 全局快捷键默认关闭，固定 Ctrl+Alt+Space/Left/Right/L/U；逐项报告冲突，保留可用组合，关闭/退出释放注册。
- 15/30/60/90 分钟睡眠定时使用单调时间；取消、替换和到期消费相互隔离。暂停/切歌/隐藏时继续，到期只停止一次，重启不恢复。

## 实际交互与边界

- 实际 Ctrl+Alt+Space 暂停合成音频、Ctrl+Alt+U 解锁歌词并更新保存偏好通过。
- 实际点击原生菜单「解锁并找回桌面歌词」恢复窗口输入，保存偏好 Locked=false；实际点击「退出飞牛音乐」后进程和歌词窗口退出，即使关闭到托盘已启用。
- 设置卡片布局正常；实际点击开始 30 分钟定时后显示倒计时，取消后恢复未设置状态并禁用取消按钮。
- Windows 托盘区域不是本次 UI 工具提供的可选窗口。菜单交互通过仅 Debug 的预览参数调用同一真实 Win32 菜单并将其放在应用可捕获范围内；发行包没有该入口。通知区域图标的双击/右键、收起主窗口后的连续菜单取消，以及真实 Explorer 重启和多显示器/DPI 操作仍列入用户验证单，不将模拟重建消息冒充真正重启。
- 没有重新执行旧 NAS 账号/权限/完整格式/安装升级矩阵；本轮未实现自定义键位、自动更新或第三方音乐源。
