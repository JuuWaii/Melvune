# 封面、歌词与原生界面

更新：2026-09-23。

## 本轮范围

以 `img/ui示意图.png` 的左侧导航、内容区和全宽底部播放器分布为参考，使用 WinUI 3 原生控件与黑白主题资源。保留真实曲库入口，不填充虚构推荐内容。歌曲行展示缩略图、标题、歌手、专辑及时间；专辑列表展示封面；底部展示当前曲目封面与专辑。歌词在右侧展开。

默认读取 Windows 应用主题并监听变化；不修改系统设置。主题资源同时覆盖选择标记、音量/进度滑块和勾选控件。手动主题偏好、桌面歌词及更小窗口的进一步自适应仍在后续范围。

## 数据与行为

- 飞牛：歌曲/专辑 `coverId`，同源 GET `static/cover?coverId=…&size=256`；GET `lyric/list?trackGUID=…` 的 `list`、`preferred` 及各项 `content/guid/source/offset`。
- 歌词优先选择服务端指定版本，否则优先内嵌、同目录 LRC、手动来源中的有效时间轴版本，最后回退纯文本。支持多时间戳、毫秒、同时间翻译行合并、LRC offset 和服务端毫秒偏移。
- 本地：读取系统音乐元数据的专辑名；优先同名 JPG/PNG，再目录 `cover.jpg`、`cover.png`、`folder.jpg`，最后 Windows 音乐缩略图（内嵌封面）。歌词读取同名 `.lrc`，支持 UTF-8 和带 BOM 的 Unicode。
- 当前行随播放进度高亮并滚动，点击定时歌词调用现有播放器跳转。纯文本歌词不跳转。停止播放清空当前封面/歌词，切歌取消旧歌词和图片加载，旧会话封面不写回。
- 封面请求最多 4 个并发、15 秒上限、96 张内存缓存；单图最多 4 MiB，解码宽度 256。拒绝重定向与非图片响应，失败保留占位；不缓存凭据或将私有图片写入磁盘。
- 本地附属文件不跟随链接；歌词读取上限 512000 字节，时间轴上限 10000 项。超限/不支持编码显示加载失败，不影响播放。

## 2026-09-24：紧凑窗口布局

窗口内容宽度低于 1100 DIP 时，底部播放控制移到第二行；左侧导航变窄并可垂直滚动，内容标题可换行，专辑列改用比例宽度。搜索与分页信息不再被右侧歌词栏压缩，详情导航超宽时可横向滚动。

紧凑窗口中的歌词占用完整内容区，覆盖期间禁止下方列表接受输入。关闭歌词、切换分类或重新搜索/翻页会恢复列表；扩大窗口则恢复歌词与歌曲并排、播放器单行布局，不清空队列或重建音频。补充窗口关闭后的媒体加载保护，播放不可用来源时清空上一首的封面/歌词。

已实际检查 820×820 浅色窗口、展开歌词和最大化后的布局恢复。窗口状态回归共 57 项通过，Release 构建与隐私扫描通过。新增窗口断言覆盖播放器换行、歌词覆盖时列表禁用、分类导航恢复、歌词关闭后恢复及宽窗口还原。更多 DPI、极小窗口与真实系统主题通知仍待验证。Debug 参数 `--preview-synthetic --preview-compact --preview-light` 可复现紧凑预览。

## 2026-10-01：刷新后迟到封面隔离

音乐库刷新或重新关联会用相同来源 ID 注册新的扫描实例。此前旧实例已经开始的封面请求仍可能在缓存清空后完成，按相同键写入旧图片。现在本地封面写回前同时核对当前注册的实例引用；实例已替换或移除时丢弃结果，下一次请求从当前实例加载。此保护与现有曲目上下文、请求取消、飞牛会话检查一起执行。

窗口回归夹具在真实 PNG 解码后暂停写回，用同 ID 的新扫描实例替换来源，再释放旧请求；验证旧图片不会显示或入缓存，并验证新实例仍可加载有效封面。检查只操作生成的本地音乐库，不读取用户目录或修改 NAS。

最终 127 项窗口回归全部通过，报告阶段 complete、无失败；Debug/Release 构建零警告、零错误，隐私扫描通过。首次运行后续扫描取消检查的夹具仍比较替换前的对象，已改为以当前实例为基准，并重新运行完整回归确认。固定 preview.4 包尚未包含修复。
