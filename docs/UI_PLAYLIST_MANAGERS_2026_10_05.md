# 歌单类别管理页

左侧“飞牛歌单”“本地歌单”类别按钮分别进入对应管理页；具体歌单仍可从侧栏直接打开。管理页使用与音乐库管理一致的主内容导航，保留侧栏、播放栏和现有页面动画，提供名称筛选、新建、刷新，以及每张卡片的打开、改名、删除图标。

从管理卡片打开详情后，返回会回到对应类别并恢复歌单选择；再次返回恢复原来的首页、曲库或设置页。导航保留播放源与队列，保存时禁止离开，读取中可以离开，旧页面的迟到响应不会重新打开页面。

本地歌单保存于本机，可包含跨库歌曲；删除确认默认取消，只删除歌单，保留音乐文件。飞牛歌单绑定当前来源和账号，沿用已有的权限、快照冲突检查及写后回读；只读来源可打开但不能创建、改名或删除。飞牛卡片不显示接口未提供的曲目数量，需打开详情读取。创建和改名仍使用命名弹窗，删除仍有确认，避免主页面出现常驻表单。

实际鼠标复核使用独立的合成数据窗口，确认本地类别入口、第二张卡片打开对应详情、详情返回管理页、改名弹窗取消后数据保持、名称筛选结果正确。没有对真实 NAS 进行本轮写入，也没有通过鼠标确认删除。取消弹窗后的无关播放提示已修正为歌单数量提示，并加入回归检查。

原生窗口回归覆盖两类管理页、卡片图标与可访问名称、名称筛选/空结果、新建后保持管理页并选中新歌单、改名同步卡片和侧栏、删除取消及只删除选中项、详情返回、保存导航保护、只读来源及迟到列表保护。飞牛写入使用隔离接口夹具，不代表真实 NAS 新 UI 验收。验证结果及最新运行目录见 NATIVE_BACKLOG.md。
