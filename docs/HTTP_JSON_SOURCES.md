# 自定义 HTTP/JSON 音乐源

rc.4 首版面向可匿名读取 JSON 歌曲目录、原始音频、封面和歌词的自建服务。它将这些歌曲接入同一播放器与跨库本地歌单。当前只读，不要求或保存账号凭据，不修改服务端内容；本批集中回归和真实服务兼容性结果见 [rc.4 验收记录](RC4_ACCEPTANCE.md)。

## 在应用中添加

音乐库管理 → 新建音乐库 → 其他音乐 · 自定义 HTTP/JSON。填写库名称、HTTP/HTTPS 服务根地址与「JSON 字段方案」。服务部署在子路径时保留该路径，例如 `https://music.example.com/catalog/`。填写有效方案后才能保存；保存时读取完整目录，加载失败不提交新配置。

所有音乐中的「自定义 HTTP/JSON」分类可浏览和按曲名、歌手、专辑搜索。双击播放，右键加入本地歌单。封面、歌词、定位、桌面联动与正常关闭后单曲续播沿用现有播放控件。原始音频要求服务支持 HTTP Range。

卡片右侧编辑仅可修改名称；服务地址、字段方案与来源类型保持只读。更换这些内容应新建音乐库，以保护歌单和续播中的来源身份。刷新音乐库重新读取目录；暂时网络或响应错误保留已加载的完整目录，401/403 单独撤销该来源。删除需要确认，只移除客户端的连接方案，服务端音乐保留，本地歌单中的缺失引用保留为不可用。

## 默认字段方案

以下是编辑器自带的声明式方案；可修改已知字段的值以匹配自己的接口。不支持表达式、函数或脚本。

```json
{
  "version": 1,
  "listPath": "api/tracks",
  "itemsPath": "data.items",
  "totalPath": "data.total",
  "pageParameter": "page",
  "pageSizeParameter": "size",
  "pageSize": 100,
  "firstPage": 1,
  "idPath": "id",
  "titlePath": "title",
  "artistPath": "artist",
  "albumPath": "album",
  "durationPath": "duration",
  "durationUnit": "seconds",
  "playUrlPath": "url",
  "coverUrlPath": "cover",
  "lyricsUrlPath": "lyrics"
}
```

按上述根地址及方案，第一页请求为 `https://music.example.com/catalog/api/tracks?page=1&size=100`。接口响应示例：

```json
{
  "data": {
    "total": 1,
    "items": [
      {
        "id": "song-001",
        "title": "示例歌曲",
        "artist": "示例歌手",
        "album": "示例专辑",
        "duration": 180,
        "url": "audio/song-001.flac",
        "cover": "covers/song-001.jpg",
        "lyrics": "lyrics/song-001.lrc"
      }
    ]
  }
}
```

媒体相对地址基于服务根地址解析，不基于列表接口目录。也可提供同源绝对地址。`id` 必须是非空字符串或非负整数，完整目录内唯一且在刷新间稳定；时长为非负数，单位可选 `seconds` 或 `milliseconds`。标题、歌手、专辑、时长、封面和歌词字段可缺失；歌曲播放地址必需。缺失标题显示「未命名曲目」。

字段路径以点号访问对象成员，例如 `song.title`；实际响应中的成员名称区分大小写，不支持数组索引。`itemsPath` 留空表示响应根本身是歌曲数组，`totalPath` 留空表示不使用总数；其他可选映射路径可留空以关闭相应字段。配置属性使用以上已知名称，拒绝未知或重复配置属性。

`listPath` 只能是服务根地址下的相对目录路径，不能含查询、片段、百分号、父目录或 URL。页号、页大小参数是简单名称；`pageSize` 为 1–1000，`firstPage` 为 0–1000000。最多读取 10000 首；完整页面后继续翻页，总数满足或收到不足一页时结束。总数发生变化、重复 ID、异常页面或不完整总数均视为加载失败，不用半份目录替换此前完整目录。

## 首版兼容边界

列表、原始音频、封面和歌词必须允许匿名 GET，不发送 Cookie、默认 Windows 凭据或 Authorization。服务与媒体地址的协议、主机和端口必须一致；媒体地址不允许查询参数、片段、URL 内账号密码或跨源跳转，不自动跟随重定向。签名 URL、认证头、跨域 CDN、脚本转换与其他协议后续开发。

单页 JSON 最大 8 MiB，封面最大 4 MiB 且应返回 `image/*`，歌词最大 512000 字节。歌词文件应为 UTF-8（可含 BOM）LRC 或纯文本；不支持任意 JSON 歌词接口格式。缺少封面或歌词时相关显示为空，支持的内嵌歌词可由现有解码流程提供。原始音频的解码能力沿用本应用 FFmpeg。

本地连接配置保存名称、根地址与字段方案，不保存歌曲音频/封面/歌词资源地址；资源地址在成功读取目录后进入内存。连接不是音频缓存：服务器离线时无法新开媒体流。与其他来源相同，真正退出保存当前一首和实际进度，重启保持暂停并等待来源可用。

真实服务验收请用不包含私人信息的独立测试接口，按 [用户验证单](RC4_USER_VALIDATION.md) 记录目录、Range、封面、歌词和分页结果。该入口不承诺任意 REST 服务自动适配。
