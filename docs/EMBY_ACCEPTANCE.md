# Emby 只读音乐源首版

本批新增音乐库管理中的 Emby 连接创建、编辑与确认删除，独立来源 UUID、当前 Windows 用户 DPAPI 登录令牌、所有音乐的来源筛选及曲名/歌手/专辑搜索。支持默认原始音频 Range 播放、歌曲或专辑封面、已有解码器支持的音频内嵌歌词，以及混合本地/Emby 歌单和关闭后续播。保持 WinUI 黑白样式，不引入服务端写入。

地址规范保留反代子路径，接受服务器根或 `/emby/` API 根。认证先获取令牌和不可变用户 ID；服务地址、账号或用户 ID 改变要求新建音乐库，不能把旧歌单改指另一账号。密码仅用于本次登录，不保存；令牌放请求头，默认拒绝重定向。每个来源读取上限 10000 首，完整分页的一致性、重复与大小校验通过后才替换目录；暂时离线保留此前目录，401/403 单独撤销该来源并保留续播进度。

保存/删除的原子连接索引替换为提交点，失败时保留旧配置并清理新凭据槽，提交后的凭据清理失败不会被误报为操作失败。编辑留空密码保留已加密令牌，改名保持歌曲身份；删除只影响客户端连接和令牌，音乐文件和本地歌单引用保留。

实现依据：[用户认证](https://dev.emby.media/doc/restapi/User-Authentication.html)、[用户范围目录](https://dev.emby.media/doc/restapi/Browsing-the-Library.html)、[音频流接口](https://dev.emby.media/reference/RestAPI/AudioService/getAudioByIdStream.html)。首版选择默认主音频原始流，不新增多版本选择或转码。没有稳定的通用服务端歌词契约，歌词只使用已实现的内嵌解码路径，不宣称插件兼容。

集中验证：协议与连接存储共十组专项通过；覆盖认证 JSON、令牌头、重定向拒绝、分页边界与取消、元数据空值、封面与 Range 跳转、身份隔离、有界文件、原子保存回滚与文件锁。Debug 应用/测试构建均 0 警告、0 错误。实际 WinUI 受控协议窗口 25 项、既有桌面/设备/主题 152 项、Navidrome 窗口 20 项通过。Emby 原生静音 WAV 恢复播放的首次 Playing 事件为保存的 15 秒；窗口专项涵盖认证撤销隔离、连接恢复、混合歌单及删除引用保留。续播六个独立进程的 68 项窗口检查及关闭后磁盘记录/清空删除回归通过。报告在 `.review-audit/emby-20261013/`，均使用独立配置，无真实账号写入。

真实 Emby 服务尚未提供，版本、代理、账号权限、实际声音及内嵌歌词格式需要用户环境验收。服务端收藏/歌单写入、专辑歌手独立页面、插件歌词、转码、自定义源和新完整安装器后置。本批独立 ZIP 保留旧包，未上传发布；最终 Release 的键鼠交互按用户验证单检查，不以 Debug 方法调用代替。

核心基础完整回归 120/120 通过；来源代码及 Git 历史隐私扫描无未审查阻断项。窗口与存储专项的合成凭据不是真实账号，扫描仅保留精确审核过的历史合成值例外，不豁免整份测试文件。
