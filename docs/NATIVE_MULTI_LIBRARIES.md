# 多目录音乐库阶段

2026-09-26。已实现多个本地目录并存、库命名、分组与库筛选、曲目来源标签、独立刷新、移除以及文件夹重新关联。支持最多 100 个库，每库 10000 首；文件不复制、不上传、不删除。

配置 local-libraries.json 使用版本号、原子替换和跨进程写锁。首次读取兼容 local-music.json，保留原 SourceId；旧文件保留作为历史备份，存在新配置后不再自动导回。重复目录拒绝，重新导入同一路径复用身份。并发改动提示重试，损坏文件不覆盖。

本地歌单打开时恢复已保存的本地来源；不同库内同名文件不合并。离线库及歌单引用保留。修改库目录时先扫描成功再保存，保持来源 ID；相对路径不变的歌曲可以重新关联。单个文件改名或相对路径变化仍需要重新加入歌单，未声称自动重关联。

刷新重新枚举文件，运行期间按大小和修改时间复用未变化文件的元数据，只读变化/新增项的标签。缓存只在内存中；重启完整扫描，不监听文件系统事件。移除库取消注册并移除该来源的播放队列项，但不删除持久化歌单引用。纯本地跨库队列不受飞牛会话重置影响。
