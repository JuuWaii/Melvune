## 2026-10-01：刷新取消与一致性

修复本地刷新取消后曲目列表空白的问题。用户取消扫描时直接恢复原本地列表、选中项、页码和分页按钮；从飞牛页面进入时，飞牛旧列表不能被恢复为本地列表。页面导航取消旧请求时，不覆盖新页面。

多库刷新先暂存各库扫描结果，全部扫描结束后统一应用。取消第二个库的扫描，不会提前替换已扫描完成的第一个库；来源身份、歌单引用及已有播放流保持。扫描本身的结果提交不会回滚刷新开始时从磁盘读取到的外部目录配置变更。单个库读取失败继续保留该库旧快照，其他成功结果在本轮结束后应用。
