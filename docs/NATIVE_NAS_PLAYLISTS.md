# 飞牛专属同步歌单

2026-09-26。侧栏“飞牛歌单”与“本地歌单”同级，绑定当前飞牛账户。支持列表、创建、改名、增删当前账户曲库的歌曲、删除歌单、显式刷新和播放。只允许同源曲目加入；本地文件不能按同名曲目自动映射至飞牛。

## 当前服务器契约

重新读取当前实例前端后核对，旧 entry.js 的散列已变化。前端静态模块确认如下请求，随后使用真实实例验证。只记录结构，不记录地址、账号、歌曲 ID 或会话。

- GET playlist/list，无分页参数，data.list。
- GET playlist/detail?guid=，data 为 guid/name/coverId/createdAt/updatedAt 对象。
- GET track/playlist-detail/list?playlistGUID=&page=&size=&sort=trackAddedAt,asc，data.list/total。
- POST playlist/create：name、coverId（首版 null）；返回创建对象。名称 1–32 字符。
- POST playlist/edit：guid、name、coverId，保留原封面。
- POST playlist/add-track、playlist/remove-track：guid、trackGUIDs 数组。
- POST playlist/delete：guid。

读取/编辑快照限制 10000 首，每页 100 首；超过上限拒绝编辑，避免把部分集合保存成完整集合。CUE 不进入播放队列。未观察到自定义排序写入接口，当前按加入时间排序。

## 同步与冲突边界

编辑前重新读取并比较名称、封面、更新时间；增删歌曲和删除歌单还检查完整成员顺序。写入后回读并核对预期结果。冲突、网络失败或结果不一致时清空可编辑快照，提示刷新核对；不自动重发创建或写入。切换/退出账户时取消未完成操作并关闭对话框。

这是保存前检查及保存后确认。当前观察接口没有原子版本条件，检查与写入之间仍有竞态窗口，不能宣称服务端事务级冲突锁。网页变动通过“刷新”获取，没有实时推送。服务器升级后需重新核验契约。

## 2026-10-02 网页与原生界面交替编辑

用户手动登录独立 Chrome 配置后，以浏览器可见控件和原生 WinUI 窗口完成交替操作。网页新建唯一临时歌单，客户端打开后直接读取到该歌单；客户端加入歌曲和改名后，网页刷新显示相同结果。网页改名后，客户端用旧快照改名被拒绝，编辑按钮禁用并提示刷新；网页新名称未被覆盖，客户端刷新后读取到新名称。

网页移除临时歌单内的歌曲引用后，客户端用旧成员快照添加歌曲也被拒绝，网页仍为零首；客户端刷新读取空歌单。随后网页从歌曲菜单重新加入歌曲，客户端刷新显示同一歌曲；客户端移除后网页刷新为零首。最后从客户端删除本次创建的空歌单，网页刷新确认该歌单消失，原有歌单仍可读取且保留两首歌曲。没有修改原有歌单、收藏或音频文件。
