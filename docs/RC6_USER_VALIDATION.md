# rc.6 使用与验证

从 ZIP 解压后运行 FnMusic.App.exe，或使用便携 EXE。旧包保留，新版为非官方未签名候选版；不覆盖仍在运行的旧包。

1. 侧栏只有一个歌单列表，默认隐藏飞牛同步歌单。打开「音乐管理 → 歌单」可创建/编辑/删除本地或飞牛歌单、筛选名称；开启「在侧栏显示飞牛歌单」后与本地歌单一起排列，图标区为飞牛官方标志。
2. 「音乐管理」内切换音乐库与歌单分页。侧栏底部不再重复导入及设置，音乐库创建/编辑仍在管理页；设置保留标题栏齿轮。
3. 「设置 → 播放」：SMTC 用于 Windows 媒体面板与播放控制；「允许本机应用读取播放信息与歌词」供适配 FNMusic 协议的应用只读接入，默认关闭，互相独立。
4. 首次关闭选择收起、退出或取消；记住后设置同步，下次不再询问。不记住则下次启动再询问。收起后可从托盘恢复，托盘退出始终退出。托盘不可用时保留窗口。
5. 切换歌词页、队列与管理页，检查动画及响应。隐藏桌面歌词期间减少后台调度；恢复时歌词应为最新内容。硬件合成由 WinUI 管理，未承诺固定 FPS。
6. 正常退出并重启，确认既有歌曲队列、进度与歌单保持；点击播放继续，不自动出声。
