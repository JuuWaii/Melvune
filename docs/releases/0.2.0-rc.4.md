# 0.2.0-rc.4 — 自定义 HTTP/JSON 音乐源

本版新增匿名、同源、只读的自定义 HTTP/JSON 来源，将可映射的歌曲目录接入现有播放器、封面、歌词、跨音乐库本地歌单与关闭后单曲续播。目标为统一 Windows x64 ZIP 与便携 EXE；本轮实现及集中回归已完成，最终来源修订、摘要和交付状态以仓库 `docs/NEXT_DEVELOPMENT_CHECKLIST.md` 与 `docs/RC4_ACCEPTANCE.md` 为准。

音乐库管理 → 新建音乐库 → 其他音乐 · 自定义 HTTP/JSON，可填写库名称、根地址和 JSON 字段方案。方案配置列表接口、受控分页、稳定歌曲 ID、标题/歌手/专辑/时长、音频/封面/歌词地址；有效配置才允许保存，目录完整读取后才提交。所有音乐新增对应来源分类，原始播放要求服务器支持 HTTP Range。

最多 10000 首，仅接受匿名 GET 和同源、无查询参数的媒体地址，不执行脚本、不发送账号凭据或 Cookie，不自动跟随重定向，不支持签名 URL、认证头和跨域 CDN。歌词支持 UTF-8 LRC/纯文本，不能直接映射任意 JSON 歌词对象。完整方案示例见随包 `HTTP_JSON_SOURCES.md`。

编辑可改名称，地址与映射需新建来源，避免原歌曲身份指向不同媒体。暂时读取失败保留已加载的完整目录，401/403 单独撤销对应来源；保存或删除提交后不会因二次读取失败而否认成功。删除只移除客户端连接，服务端文件与本地歌单引用保留。

本版继承 rc.3 的飞牛与本地音乐、Navidrome/Emby/Subsonic 只读来源、两类歌单、应用内歌词和右侧队列、透明桌面歌词及锁定穿透、托盘、SMTC、固定全局快捷键、睡眠定时、设备监视与本机只读信息接口。第三方服务端写入、转码、完整队列恢复和自动更新后置。

Windows 10 2004（19041）及以上 x64。ZIP 保持完整目录运行 `Start-FnMusic.cmd`；便携 EXE 放在可写目录，配置在旁边 `FnMusic-portable\Data`。升级前正常退出旧版并备份配置，两个入口不自动迁移数据。运行库、解码库、许可和对应解码器源码随包提供；候选版未签名，旧包保留。

集中验证和实际运行边界见 `RC4_ACCEPTANCE.md`，用户反馈按 `RC4_USER_VALIDATION.md`。受控协议和窗口检查不能代表真实服务器、听音、硬件、所有 DPI/编码组合通过。本轮仅本地交付，完整安装器和远端发布另行安排。
