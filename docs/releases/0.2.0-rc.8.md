# Melvune 0.2.0-rc.8 · Windows x64

Melvune（合听）是从原飞牛音乐 Windows 客户端发展而来的多来源音乐播放器。本次将应用、源码项目、命名空间、程序集、资源及交付链统一为 Melvune，并整理项目文档、下载入口与 AI 辅助开发声明。

## 下载与使用

| 附件 | 用途 |
| --- | --- |
| Melvune-0.2.0-rc.8-win-x64-portable.exe | 放在可写目录启动，校验并解包到旁边的 Melvune-portable；配置位于其 Data 目录 |
| Melvune-0.2.0-rc.8-win-x64.zip | 完整解压，运行 Start-Melvune.cmd 或 Melvune.App.exe |
| SHA256SUMS.txt / release.json | 本次云端构建的附件校验和、源码与工作流来源 |
| USER_GUIDE.md / RELEASE_NOTES.md / AI_DISCLOSURE.md | 使用指南、版本说明与 AI 声明 |

支持 Windows 10 2004（19041）及以上 x64，运行时与解码依赖随包提供。此版本**未签名，作为 Pre-release 发布**；完整安装器、签名和自动更新后续提供。

## 主要功能

- 本地多音乐库、持久索引与后台扫描；飞牛音乐、Navidrome、Emby、Subsonic 兼容及匿名同源 HTTP/JSON 音乐源。
- 跨来源本地歌单、飞牛同步歌单与统一音乐管理；飞牛服务端管理操作按账号权限开放。
- 封面、受支持的内嵌/外部歌词、应用内歌词页、右侧播放队列、黑白主题和系统主题跟随。
- 正常退出保存完整队列与当前进度，重新启动保持暂停，点击播放继续。
- SMTC 系统媒体控制、透明桌面歌词与锁定穿透、托盘、睡眠定时、可选全局快捷键和音频输出设备监视。
- 可选的当前 Windows 用户只读播放信息与歌词接口，与 SMTC 独立，默认关闭。

## 配置变化

新版使用独立配置与来源身份，不自动迁移或复用改名前的账号、歌单、数据目录和发现协议。普通 ZIP 配置位于 `%LOCALAPPDATA%\Melvune.Native`，便携 EXE 使用旁边 `Melvune-portable/Data`。请重新添加来源与登录；旧个人数据和历史包保留原样。

## 验证范围与限制

发布工作流从本次标签提交重新构建 ZIP 和便携 EXE，执行核心/来源/队列与脚本回归、当前源码及历史隐私检查，验证全部载荷文件、CRC、逐文件摘要、便携尾部、版本、源码来源和七档图标。附件上传后，再比较 GitHub 返回的大小和 SHA-256 digest，全部一致才公开。

同一应用实现此前本地通过核心 121 项、Node 24 项、便携完整性 24 项、独立信息消费者 9 项及窗口综合 954 项等检查；ZIP 和便携实际启动、正常退出与暂停续播已验证。上述本地检查不等于所有云端产物、真实服务器和硬件组合均已人工验收。详细范围见仓库 `docs/RC8_ACCEPTANCE.md` 与 `docs/RC8_USER_VALIDATION.md`。

Navidrome、Emby、Subsonic 接入当前只读且不转码；HTTP/JSON 仅匿名同源访问。飞牛网页歌单修改需刷新，不承诺实时同步或并发事务。全部编码、DPI、实体媒体键、硬件热插拔和长期压力组合尚未全面验证。强制终止、崩溃或断电不保证保存最后播放位置。
