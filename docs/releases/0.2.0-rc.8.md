# Melvune 0.2.0-rc.8

Melvune（合听）将应用、源码项目、C# 命名空间、程序集、资源、构建脚本及当前交付链统一到新名称，作为支持本地与多种个人音乐源的独立播放器继续开发。飞牛音乐保留为音乐来源名称。

本轮采用独立新配置、身份与发现协议，不自动迁移或复用旧品牌账号、歌单和数据目录。ZIP 从 `Start-Melvune.cmd` 或 `Melvune.App.exe` 启动，便携 EXE 使用同级 `Melvune-portable/Data`。旧目录与历史包保留原样。

新便携格式使用 `MELVUNE-PAYLOAD-1`，交付前验证完整 ZIP、逐文件摘要、源码提交与便携元数据，并拒绝损坏、混合品牌或旧格式载荷。解码器构建材料同步改名并真实重建，继续随包提供依赖许可证与对应源码。

Windows x64 未签名候选版，仅提供完整目录 ZIP 和便携 EXE。集中验证、实际启动结果和已知限制见 `RC8_ACCEPTANCE.md`；包内文档为打包时快照。完整安装器、签名、自动更新和正式发布后置，真实听音及更多硬件/第三方服务若未实测不视为已通过。
