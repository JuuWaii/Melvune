# FNMusic 0.2.0-rc.6

音乐管理与界面效率候选版：统一歌单列表，飞牛同步歌单默认隐藏、可在管理页显示并以官方来源图标区分；音乐管理包含音乐库和歌单分页，侧栏入口精简。首次关闭提供收起/退出与记忆选项；明确 SMTC 与第三方只读播放信息的差异。桌面歌词隐藏时不投递快照 UI 更新，突发快照合并，稳定文字不重复写入。

沿用 WinUI 硬件合成渲染，未宣称固定 FPS 或实测 GPU 提升。继承 rc.5 完整队列/进度恢复和多来源播放。未签名，更多硬件/DPI/听音及真实第三方服务兼容待验证。请见 RC6_USER_VALIDATION.md 与 RC6_ACCEPTANCE.md；集中回归与最终本地交付已完成：核心120项、窗口927项、602文件摘要及实际管理/关闭记忆/便携续播与数据保持均通过。最终摘要见仓库 RC6_ACCEPTANCE.md，包内为打包时快照。
