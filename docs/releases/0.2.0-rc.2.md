# 0.2.0-rc.2 — 桌面播放联动候选版

新增 Windows 系统媒体信息和媒体键、独立桌面歌词、默认关闭的当前用户只读 NamedPipe 音乐/歌词接口，以及独立示例消费者。三个功能共用实际播放快照、匿名曲目代次和现有播放队列；封面和迟到歌词受代次隔离。

桌面歌词支持拖动、置顶、锁定/主窗口解锁、字号、黑白主题和屏内恢复。接口提供快照、歌词分页和订阅，有客户端/帧/文本上限和慢客户端超时。退出飞牛时保留有效本地播放；主窗口退出统一释放新服务。

交付 Windows x64 ZIP、便携 EXE、安装 EXE、MSI 和 SHA-256。程序版本为 `0.2.0-rc.2`，安装器内部版本为 `0.1.1002`，高于 rc.1 的 `0.1.1001` 并低于未来稳定 `0.2.0`。旧版产物保留。本轮本地交付，不自动上传 GitHub。

使用方法见 `DESKTOP_INTEGRATION.md`，协议见 `PLAYBACK_INFORMATION_PROTOCOL.md`，用户反馈入口见 `RC2_USER_VALIDATION.md`。未签名；自定义快捷键、第三方服务、自动更新和更多压力矩阵延期。原始候选版回归与限制见仓库 `docs/RC2_ACCEPTANCE.md`，后续批次状态见 `docs/NEXT_DEVELOPMENT_CHECKLIST.md`。


2026-10-12 UI 反馈修正：主播放栏和应用内歌词页加入明确的「词」按钮，直接显示/隐藏透明桌面歌词，并同步设置页与窗口关闭状态；歌词右键增加快速设置。媒体联动使用「SMTC 开关」命名。强调色仅用于主操作按钮及选中项背景，其余文字、图标与滑块保持黑白配色。

桌面歌词追加修正：移除白色顶边、原生窗口边框及矩形背景色差，重新激活后仍保持透明。开启「锁定并穿透鼠标」后，点击会直接交给后方窗口；设置 → 播放可解锁并找回。托盘解锁延期。此次反馈修正版仅生成独立 ZIP，保留此前产物，完整安装器重新交付保持暂停。

2026-10-12 桌面常驻增强批次：新增原生系统托盘、播放/歌词菜单和锁定歌词快捷解锁；支持可选关闭到托盘（默认关闭）和可选全局播放/歌词快捷键（默认关闭，冲突提示）。设置页增加 15/30/60/90 分钟睡眠定时，切歌、暂停和隐藏主窗口时持续计时，到期只停止播放一次，重启不恢复。托盘解锁从前批延期项提升为本批功能。保持独立 ZIP 交付和旧产物，不重新封装完整安装器。

2026-10-12 音频输出可靠性批次：设备增删更新和系统默认变更自动刷新列表，显式设备断开后尝试回退默认。异步旧结果不覆盖新选择，刷新不重复设置同设备；切换失败恢复已确认选择，读取异常明确提示。保留播放源、队列、暂停、音量与静音，不强制续播或重开歌曲。真实 USB/蓝牙/驱动拔插及无声隙恢复仍需硬件验收，独立 ZIP 不覆盖旧批次。
