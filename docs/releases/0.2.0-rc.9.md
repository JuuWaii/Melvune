# Melvune 0.2.0-rc.9 · Windows x64

本次补齐 Windows 安装 EXE 与 MSI。四种入口均由同一标签源码构建，包含相同应用与解码依赖。

| 附件 | 使用方式 |
| --- | --- |
| Melvune-0.2.0-rc.9-win-x64-setup.exe | 常规安装入口，Options / Browse 选择可写目录 |
| Melvune-0.2.0-rc.9-win-x64-setup.msi | 中文目录选择页，与 EXE 选择一种即可 |
| Melvune-0.2.0-rc.9-win-x64-portable.exe | 首次解包到旁边 Melvune-portable，配置位于 Data |
| Melvune-0.2.0-rc.9-win-x64.zip | 完整解压后运行 Start-Melvune.cmd |
| SHA256SUMS.txt / release.json | 所有附件摘要、源码与工作流来源 |

支持 Windows 10 2004（19041）及以上 x64，运行时随包提供。此版本未签名，公开为预发布版。

安装版按当前用户安装，默认 `%LOCALAPPDATA%\Programs\Melvune`；安装路径保留供维护和卸载使用，卸载保留 `%LOCALAPPDATA%\Melvune.Native` 配置。采用独立 Melvune 安装标识，不迁移改名前应用。内部 MSI 版本为 0.2.1009，应用显示 0.2.0-rc.9。

开发流程调整：日常仅按需要生成可运行 Debug 预览；最终发布时再统一生成 ZIP、便携、EXE 和 MSI。旧开发预览按保留最近3份及7天内产物的规则定期清理；历史发布包、个人数据与验证证据不在清理范围。

发布作业验证完整便携载荷、MSI 每个文件、EXE 内嵌 MSI、目录选择、当前用户范围及图标，并在独立 Windows runner 上实际执行三组静默安装/卸载检查。全部检查与远端附件摘要匹配后才公开。图形安装、SmartScreen、跨版本升级和全部硬件/服务器组合仍需用户验证；功能与限制继承 rc.8。

项目在 AI 广泛协助下开发，部分代码、测试、文档和脚本由 AI 生成或修改，需求和发布由维护者负责。Melvune 使用 MIT 许可；FFmpeg 对应源码与 LGPL 材料随包提供，安装器的 WiX MS-RL 声明见 WIX_NOTICE.md / WIX_LICENSE.txt。
