# 0.2.0-rc.3 — 统一多音乐源候选版

本版本将此前功能批次整合为同一 Windows x64 候选版，避免音乐源、桌面能力和关闭后续播分别对应不同下载包。当前目标是本地 ZIP 与便携 EXE；完整安装器和远端发布后置。最终产物、校验值与交付状态以仓库 `docs/NEXT_DEVELOPMENT_CHECKLIST.md` 为准，未完成的检查不作通过承诺。旧版本和安装器保留供回退。

## 当前能力

- 飞牛音乐与本地音乐、音乐库管理、启动索引恢复及后台扫描；跨来源本地歌单与当前账号飞牛歌单。
- Navidrome、Emby 与通用 Subsonic 兼容只读来源，分别保存连接和加密凭据，支持目录、搜索、原始 Range 音频、封面及可用歌词；第三方歌曲可加入本地歌单。
- 正常退出保存当前一首及实际位置，重启保持暂停，点击播放继续。来源暂时离线保留记录，显式停止归零，清空队列或移除当前歌曲取消恢复。
- 应用内歌词、右侧播放队列、透明桌面歌词及锁定穿透、托盘解锁、SMTC 开关、固定全局快捷键和睡眠定时。
- 输出设备自动监视，设备断开时尝试回退系统默认；保留播放来源、队列和暂停状态。Windows 黑白主题及仅主操作/选中背景使用强调色。
- 默认关闭的本机只读音乐/歌词接口，以及包内独立示例消费者。

第三方保存和删除提交成功后，后续刷新失败会单独报告；临时读取错误保留此前完整目录。歌词接口无内容或失败时可尝试受支持的音频内嵌歌词，旧请求不会覆盖新歌曲。歌曲身份包含独立来源实例，删除客户端连接不删除服务端音乐或本地歌单引用。

## 使用与升级

Windows 10 2004（19041）及以上 x64。ZIP 保持完整目录，运行 `Start-FnMusic.cmd`；便携 EXE 在可写目录首次解包，个人配置在旁边 `FnMusic-portable\Data`。运行库、解码库、许可和对应解码器源码随包提供。程序未签名。

升级前正常退出旧客户端并备份配置，使用独立程序目录；不要同时运行两版写入同一配置。ZIP 默认使用 `%LOCALAPPDATA%\FnMusic.Native`，便携使用独立 Data，两者不自动迁移。完整操作见随包 `USER_GUIDE.md`；集中反馈见 `RC3_USER_VALIDATION.md`。

## 验证范围与后续

本轮集中检查与包完整性证据见仓库 `docs/RC3_ACCEPTANCE.md`。受控协议、真实 WinUI 窗口方法和独立进程验证不能替代所有真实服务、键鼠和硬件兼容性检查。第三方真实服务器尚待提供，系统媒体卡片、实体媒体键、USB/蓝牙设备、更多 DPI 和长期压力组合继续按用户验证单验收。

Subsonic 兼容源通过标准专辑目录读取，最多 10,000 首，不保证未归入专辑的歌曲；Emby 首版最多 10,000 首。原始播放要求服务器支持 HTTP Range；服务端歌词能力依接口与格式而定。飞牛网页歌单修改需显式刷新，不承诺实时推送或并发事务。素材库任务消失不代表完成；重关联缺少完成计数时保留未确认状态。

任意 HTTP/JSON 源映射、第三方服务端收藏/歌单写入、转码、完整队列恢复、自定义快捷键、FN Connect/OAuth、自动更新、完整安装器与远端发布不属于本轮交付。正常退出进度保存不保证崩溃、断电或强制结束进程后的最后位置；信息接口需要第三方按协议接入。
