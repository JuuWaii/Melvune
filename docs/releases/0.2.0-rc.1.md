# FNMusic 0.2.0-rc.1 · Windows x64 便携候选版

提供 WinUI 原生客户端，支持飞牛音乐和本地音乐、多库分类、跨库本地歌单、飞牛专属歌单、封面与应用内歌词、右侧播放队列、主题与输出设备。启动先恢复本地索引，后台检查变化；远程媒体使用准确定位和受限范围缓存。

本候选版修复后台任务刷新误选：任务消失、ID 被复用或读取失败后清除可操作快照，不会自动切到其他任务；原任务身份恢复或用户明确选择后才可操作。统一版本与使用说明，加入独立配置目录启动参数，随包提供对应解码源码、补丁、构建参数、第三方许可与自包含运行时 NOTICE。

解压完整目录，双击 Start-FnMusic.cmd。支持 Windows 10 2004 及以上 x64；.NET、Windows App SDK 与解码库随包附带，无需另装 FFmpeg。升级前关闭旧客户端，备份 %LOCALAPPDATA%/FnMusic.Native；本地歌单 v2 不兼容 preview.5 及更早。使用方式见 USER_GUIDE.md，集中用户验证见 RC1_USER_VALIDATION.md。

已知限制：MP3 远距离首次定位可能读取较多数据；重关联缺少完成计数时结果仍未确认。第三方音乐源、FN Connect/OAuth、桌面歌词、媒体键/托盘、对外接口、安装器和自动更新后续提供；全部编码/DPI/触摸与长期压力组合未承诺。此候选版未签名。

本软件使用 [FFmpeg](https://ffmpeg.org/)（LGPL 2.1 或更高版本），完整对应源码包含在同一 ZIP 的 licenses/corresponding-source/decoder-corresponding-source.zip；参见 BUILDING_SOURCES.md。FNMusic 为 MIT 许可的非官方客户端，与飞牛官方无关联或背书。

最终推荐产物、完整 SHA-256、本轮源码提交与实际验收证据以 docs/RC1_ACCEPTANCE.md 为准。此文件可直接作为发布正文，上传时附同一 ZIP 和 SHA256SUMS.txt；当前仅完成本地交付，不表示已上传。
