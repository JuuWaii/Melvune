# FnMusic 0.2.0-rc.1 · Windows x64

WinUI 原生客户端候选版，支持飞牛音乐与本地音乐。本次发布包含黑白飞牛音符图标、可选择目录的 EXE/MSI 安装器、单文件便携入口与完整 ZIP。

## 下载与使用

| 附件 | 使用方式 |
| --- | --- |
| FnMusic-0.2.0-rc.1-win-x64-setup.exe | 常规安装入口；Options → Browse 选择目录 |
| FnMusic-0.2.0-rc.1-win-x64-setup.msi | 中文目录选择页；和 EXE 安装器选择一种即可 |
| FnMusic-0.2.0-rc.1-win-x64-portable.exe | 在可写目录运行，首次启动解包到旁边的 FnMusic-portable |
| FnMusic-0.2.0-rc.1-win-x64.zip | 解压完整目录，运行 Start-FnMusic.cmd 或 FnMusic.App.exe |
| SHA256SUMS.txt / ZIP 同名 SHA256SUMS | 校验附件；以本次云端构建附带的哈希为准 |
| release.json / WiX 许可 | 应用和封装源码来源、版本、签名状态及安装器许可 |

支持 Windows 10 2004（19041）及以上 x64。.NET、Windows App SDK 与 FFmpeg 解码动态库随包提供，无需另装依赖。安装版默认按当前用户安装，可自选可写目录，保存目录供维修和卸载恢复；卸载保留个人配置。内部 MSI 版本为 0.1.1001，应用显示版本仍为 0.2.0-rc.1。

安装版与普通 ZIP 的配置默认在 `%LOCALAPPDATA%\FnMusic.Native`；便携 EXE 使用 `FnMusic-portable\Data`。升级前退出旧客户端并备份配置，不同时运行两版写入同一目录。跨 Windows 用户或机器后需重新登录，本地歌单 v2 不兼容 preview.5 及更早版本。

## 功能与修正

- 飞牛与本地完整音乐列表、收藏、搜索、专辑/歌手、多库分组和后台扫描。
- 跨库本地歌单、当前账号的飞牛歌单、封面与应用内歌词、右侧播放队列、黑白主题与输出设备。
- 后台任务消失、身份被复用或读取失败时清除可操作快照，恢复原身份或明确选择新任务后才可操作。
- C 款黑白飞牛音符用于应用标题栏、窗口/任务栏、EXE 资源与开始菜单快捷方式。
- 修复安装 EXE 默认路径变量未展开的问题，增加目录选择，保存自选目录供卸载使用。

## 验证范围与限制

发布工作流重新执行核心/脚本测试、隐私与历史检查，核对 ZIP、便携入口、MSI 全部文件、内嵌 MSI 和七档图标资源，随后上传附件。云端构建的来源和校验和随附件发布。

同一应用/封装实现的本地实测已通过 EXE 默认/自选目录与 MSI 自选目录的静默安装/卸载，自选目录包含中文、空格和方括号；每次安装的 592 文件一致，个人配置保持。原 rc.1 核心 124/124、窗口 637/637 与实际飞牛/本地播放证据见仓库的 `docs/RC1_ACCEPTANCE.md`。这些历史实测不替代云端产物的图形安装或升级验收。

此候选版未签名。MP3 远距离首次定位可能读取较多数据；素材库重关联缺少完成计数时仍未确认。第三方音乐源、FN Connect/OAuth、桌面歌词、媒体键/托盘、对外接口和自动更新后续提供；编码、DPI、触摸与长期压力组合未全面覆盖。

## 许可与反馈

FnMusic 为 MIT 许可的非官方客户端，与飞牛官方无关联或背书。使用 [FFmpeg](https://ffmpeg.org/)（LGPL 2.1 或更高版本）；完整对应源码在 ZIP 的 `licenses/corresponding-source/decoder-corresponding-source.zip`，构建与替换见随包 `BUILDING_SOURCES.md`。运行库与安装器许可均随包保留。

详细操作见随包 `USER_GUIDE.md`，集中验证见 `RC1_USER_VALIDATION.md`。反馈提供版本、步骤、预期/实际和格式；截图与日志请隐去凭据、服务地址及私人路径。
