# 本地音乐首版

2026-09-26：多目录管理、分组、增量元数据刷新和跨库播放现已接入，见 [多目录阶段](NATIVE_MULTI_LIBRARIES.md)。以下保留早期阶段记录，单目录限制已由新实现替代。

更新：2026-09-23。

侧栏新增“本地音乐”和“导入文件夹”。通过系统选择器选择文件夹或输入完整路径，扫描目录及子目录；无需飞牛登录。读取标题、歌手和时长，支持标题/歌手搜索、每页 50 首、当前页播放队列以及手动刷新重新扫描。标签失败时保留文件名。

首版保存一个目录库。再次导入同一目录复用来源 ID，导入其他目录替换当前目录库。配置保存在本机应用数据目录的 `local-music.json`，包含目录路径与随机来源 ID；重启后进入本地音乐时重新扫描。音乐文件不复制、不修改、不上传。

扫描支持 mp3、flac、wav、ogg、opus、m4a、aac、wma、aiff、aif、ape 扩展名，最多 10000 首；扩展名匹配不保证文件可解码。跳过链接及无权限的子目录，不支持根路径或其祖先经过重解析点。扫描失败不替换已加载的来源，目录离线不删除配置。

文件的相对路径摘要作为源内 ID，库内同名文件不会合并。播放只从当前扫描快照查找文件，不把曲目 ID 解释成路径；打开时再次检查路径并交给统一播放路由和 FFmpeg。文件移动/改名会产生新引用，缺失文件播放失败，后续需增加显式重关联。

本地列表禁用飞牛收藏写入；“歌曲 / 收藏 / 专辑 / 歌手”仍是飞牛入口。已知时长的本地歌曲支持进度跳转；Windows 不支持的格式可能仍显示未知时长。标签读取逐文件设置 3 秒超时，失败不阻止整个库导入。多目录、库分类、封面、自动增量扫描和跨库歌单仍待开发。

验证：50 项原生检查通过，包含子目录、扩展名过滤、稳定身份、文件读取、错误来源/路径 ID 拒绝、配置回读、文件删除及取消。39 项窗口状态检查通过，新增本地分页、搜索、收藏禁用、回到飞牛列表，以及生成 WAV 文件通过真实本地 Provider、路由和 FFmpeg 播放且进度前进。未读取用户音乐文件，未把导入对话框鼠标操作、真实目录规模与所有格式兼容性标为已验收。

Debug 和 Release 构建通过，隐私扫描通过。测试生成的文件与窗口报告位于忽略的 `.review-audit/local-music-build/`，不发布。

## 扫描进度与取消

导入、首次读取及手动刷新扫描时，侧栏显示已读取曲目数和“取消扫描”。进度每 25 首更新并显示最终计数；未预先统计整个目录，因此不显示虚假的百分比。取消停止元数据读取，未完成结果不替换来源或写入目录配置。刷新取消后可点击“本地音乐”恢复原列表。已经完成并开始保存的导入不再显示取消按钮。

新扫描会取消尚未完成的旧扫描，旧进度回调不能覆盖新扫描状态。扫描失败或取消后，原来源与队列引用保留。基础检查增至 52 项，新增过程中取消与进度计数验证；窗口检查新增取消入口及取消后来源保持验证。以上是源码后续改进，此前交付的 preview.2 目录不自动更新。

## 飞牛会话与本地播放隔离

更改飞牛连接、重新登录、退出或登录失效时，仍连接的纯本地队列及音频不再被清空。浏览本地时保留筛选、分页和扫描；浏览飞牛时清除旧飞牛列表，但可继续本地播放。浏览本地而队列属于飞牛时，清除飞牛队列与播放，保留本地列表。

此边界目前针对单一本地库队列；尚未支持跨库混合队列的逐来源移除。此前交付的 preview.2 保留旧行为，本改进在后续源码中。

46 项合成窗口状态检查通过，新增本地浏览/本地播放、飞牛浏览/本地播放、本地浏览/飞牛队列三种组合。Debug/Release 构建零警告零错误，隐私扫描通过；未操作真实账户切换。

## 2026-09-27：混合队列隔离与歌词编码

飞牛会话变化只移除队列中的飞牛项；当前本地流继续播放，多个本地库的条目保留。若当前播放来自飞牛，停止旧流并保留剩余本地队列供手动选播。从本地返回“所有音乐”会同步清除本地筛选控件与旧分类状态。

本地歌词支持严格 UTF-8、带 BOM 的 UTF-16/UTF-32，以及无 BOM 且 UTF-8 解码失败时的 GB18030（兼容 GBK）回退。明确 BOM 的损坏内容、NUL 字符及超限文件拒绝解码。65 项基础检查通过，覆盖编码矩阵与真实 LocalMusicSource 附属歌词读取；108 项窗口回归覆盖混合队列保留、远端播放停止与歌单重新关联。Release 编译无警告错误。
