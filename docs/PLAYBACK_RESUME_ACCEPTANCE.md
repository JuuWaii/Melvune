# 关闭后续播：交付与验证

本批仅保存当前歌曲及实际位置，不持久化完整播放队列。正常退出前同步原子写入 `playback-resume.json`；记录包含来源身份与展示标签，没有音频、播放 URL、本地路径或登录凭据。记录损坏或超过大小限制时忽略并保留原文件。超长展示标签只在记录中截断，歌曲身份与进度不变。

重新启动保持暂停，先展示已保存歌曲和进度。播放时使用已恢复的对应来源打开歌曲，等待原生媒体打开和定位完成再开始播放；未连接或不可用来源保留进度并提示。托盘、全局快捷键及 SMTC 播放共用入口。主动选曲从头开始，停止将当前位置归零，清空队列或移除当前曲目取消恢复记录。关闭到托盘继续播放，真正退出才保存。
