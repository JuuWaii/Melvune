最终运行来自推荐 `-final` 目录，使用独立验证配置。用户在该实例手动完成飞牛登录并确认播放飞牛歌曲；没有自动填写认证信息。

| 验收范围 | 实际结果 |
| --- | --- |
| 本地播放与独立系统媒体控制 | 12 项通过：暂停后时钟稳定、定位到 20 秒、歌词随实际定位更新、恢复播放、独立订阅/歌词分页、上一首/下一首进入原队列、停止后元数据/代次/位置/歌词清空 |
| 系统元数据与封面 | 独立 Windows 会话匹配当前 FnMusic 曲目，实际读取状态、时间轴、能力；timed 封面 643 字节，切换无封面曲目后归零 |
| 飞牛播放与独立消费 | 13 项通过：真实非测试曲目播放、独立系统会话元数据、暂停/稳定时钟、定位/恢复、带时间轴歌词分页及当前行、持续订阅、上一首/下一首实际切歌、停止后实际播放器信息清空 |
| 桌面歌词实际鼠标操作 | 显示/隐藏、拖动、锁定与主窗口恢复解锁、字号、浅色主题、置顶关/开、关闭后播放器仍运行、重开，以及 timed/plain/empty 三种显示通过 |
| 关闭和重启 | 正常关闭后两个窗口和进程退出、发现记录为 0；重启使用新实例且播放器停止，歌词位置、主题及显示偏好保留 |
| 版本显示 | 最终主窗口和设置页均显示 rc.2 |

系统命令由独立 WinRT 进程发给当前 FnMusic 系统媒体会话，再由包内另一个自包含 EXE 读取实际播放器状态、歌词和订阅。没有用同进程内部读取代替最终接口验收。真实飞牛验收只保存通过结果、数值和歌词类型/行数，不保存账号、服务地址或私人歌曲/歌词内容。

桌面输入工具早期出现几何错误，后续重新选择窗口及完整截图后恢复操作，上述鼠标项目已实际完成。实体媒体键注入仍不受工具支持，未计作通过。
