# Melvune 使用指南

Windows x64 候选版，支持 Windows 10 2004（19041）及以上系统。ZIP保持完整目录，运行 Start-Melvune.cmd 或 Melvune.App.exe；随包包含 .NET、Windows App SDK 与解码动态库，无需安装 FFmpeg。首次启动可直接导入本地音乐。当前版本未签名，提供 ZIP 与便携 EXE 预发布候选；安装 EXE 和 MSI 均可选择当前用户的可写目录，选择其中一种安装即可；卸载保留配置。下载与云端校验和见 GitHub Release，交付状态见当前开发清单。

便携EXE放在可写目录启动，创建 Melvune-portable，个人配置位于其中Data目录。移动时一起复制EXE与整个目录；换机器或Windows用户后需重新登录。ZIP使用 %LOCALAPPDATA%\Melvune.Native，和便携配置相互独立。本轮采用新的独立身份，不自动读取旧版目录、凭据或信息发现记录，旧数据不修改。

历史 EXE/MSI 安装包仍保留，但不包含本轮新增自定义来源功能，不应将安装器版本视作本轮版本。历史安装器按当前用户安装，自选目录保存供维修/卸载恢复，卸载保留个人配置。

## 首次连接与本地音乐

标题栏齿轮 → 连接与账号：输入飞牛音乐服务的最终 HTTP/HTTPS 地址（可带 `/music/`），先连接，再输入账号和密码登录。重定向地址请改为最终服务地址。记住会话使用当前 Windows 用户的 DPAPI 加密，不保存明文密码。首次输入、双因素或特殊认证流程由用户自行完成；FN Connect、OAuth 后续支持。

音乐管理 → 音乐库 → 新建音乐库 → 本地音乐，选择目录、名称和分组。单目录含子目录最多 10000 首，首次扫描完成后保存索引；重启先显示缓存，再后台检查变化。导入和刷新在后台继续，可返回和取消；离线目录保留原列表，恢复可访问后再刷新。缓存不复制音频，离线文件不能播放。

所有音乐汇总本地、当前飞牛、Navidrome、Emby、Subsonic 兼容和自定义 HTTP/JSON 来源，可按来源筛选；库和分组筛选作用于本地音乐。回车搜索；双击歌曲播放，右键可下一首或加入本地歌单，收藏及相关歌手/专辑操作按来源能力启用。底部播放栏提供暂停/恢复、前后跳转、音量/静音、设备、模式和右侧队列。点击左下角封面进入应用内歌词，返回保留浏览上下文。歌词来源包括飞牛、支持结构化接口的 Subsonic/Navidrome、同名 LRC 和受支持的内嵌歌词。

## 关闭后继续播放

真正退出软件时会保存完整播放队列、当前歌曲及实际播放位置、播放模式和下一曲安排。重新打开后，播放栏直接显示上次歌曲和进度，保持暂停；点击播放即可继续，托盘、全局播放快捷键和 SMTC 播放命令也共用续播入口。关闭到托盘只隐藏窗口，音乐继续播放。

上次歌曲的音乐库离线或账号未登录时，进度保留；恢复对应来源后再点击播放。显式停止将该歌曲进度归零，重新选择歌曲从头播放；移除当前歌曲会取消其恢复位置并保留其他队列条目，清空队列则删除恢复记录。保存完整队列、来源身份、顺序、播放模式、显式下一曲安排和有界回退历史，不复制音频。离线引用保留但需要恢复来源才能播放；没有当前歌曲时从队列选择。最多10000首/16 MiB，未来随机结果可能不同。详细规则见 [完整队列恢复](QUEUE_SESSION.md)。此功能在正常退出时保存，不保证强制结束进程、崩溃或断电后的最后位置。

## Navidrome 音乐库

音乐管理 → 音乐库 → 新建音乐库 → 其他音乐 · Navidrome，填写名称、最终服务地址、账号和密码。服务部署在子路径时保留该路径。保存前验证连接并读取完整目录；成功后在所有音乐中选择 Navidrome，可按曲名、歌手或专辑搜索并播放，右键加入跨库本地歌单。凭据通过当前 Windows 用户 DPAPI 加密保存，原始密码不写入配置。

卡片右侧编辑可改名称和密码，密码留空使用已保存凭据；更换服务或账号请新建音乐库，以免旧歌单引用指向另一账号。刷新音乐库或 Navidrome 曲库可重试加载。重启后台恢复连接；暂时网络/目录错误保留已加载完整目录，认证失效停止该来源并提示重新输入密码。删除需确认，仅移除此客户端连接和凭据，服务端音乐及本地歌单引用保留；未连接或已从目录移除的歌曲在本地歌单中标为不可用。

当前不修改 Navidrome 服务端收藏和歌单，不提供其专辑/歌手独立页面；原始播放要求服务端支持 HTTP Range。真实部署兼容性尚待用户服务验收；其他兼容服务可使用下方的通用 Subsonic 入口。

## Emby 音乐库

音乐管理 → 音乐库 → 新建音乐库 → 其他音乐 · Emby，填写名称、服务地址、账号和密码。输入服务器根地址或已有 `/emby/` 的 API 地址均可，反向代理子路径需保留。保存前验证账号并读取用户可访问的歌曲；成功后在所有音乐中选择 Emby，可按曲名、歌手或专辑搜索。支持原始音频播放、封面、音频中的可用内嵌歌词，以及加入跨音乐库本地歌单。首版每个连接最多读取 10000 首；目录不完整或读取失败时不会以半份数据替换此前完整目录。

登录令牌通过当前 Windows 用户 DPAPI 加密，不保存原始密码；请求令牌放在头部，不写入播放 URL。编辑时可修改名称，密码留空保留令牌；需要重新认证时输入密码。更换服务或账号必须新建音乐库，以保护本地歌单中的歌曲身份。删除需确认，仅移除此客户端连接和令牌，不删除服务端音乐或本地歌单引用。飞牛退出不影响 Emby；临时连接失败保留此前目录，账号认证失效会单独撤销该来源，关闭后续播进度仍保留。

首版只读，不同步 Emby 服务端收藏/歌单，不提供转码、多版本音频选择或其专辑/歌手独立页面；原始播放需要服务支持 HTTP Range。服务端歌词插件不在首版兼容范围，真实服务器版本、代理、权限及内嵌歌词格式需按验证单验收。

## 通用 Subsonic 音乐库

音乐管理 → 音乐库 → 新建音乐库 → 其他音乐 · Subsonic，填写名称、兼容服务的最终根地址（保留部署子路径）、账号与密码。保存前验证连接并通过标准专辑接口读取目录；成功后在所有音乐中选择 Subsonic 兼容源，可按曲名、歌手、专辑搜索，原始播放、封面、加入跨库本地歌单及关闭后续播共用现有控件。

此首版按 `getAlbumList2` / `getAlbum` 读取服务端专辑中的歌曲，最多 10000 首，不保证未归入专辑的曲目。服务需要支持带盐认证和原始 HTTP Range 音频流；服务端歌词需 `getLyricsBySongId` 扩展，缺失时尝试音频内嵌歌词。暂时离线保留已加载目录，认证撤销只影响该来源。

加密凭据与 Navidrome 使用同一连接仓库，既有 Navidrome 记录兼容，不迁移歌曲身份。编辑时密码留空保留已保存凭据，更换来源类型、服务或账号须新建音乐库；删除只移除客户端连接，音乐与本地歌单引用保留。此入口不代表任意 REST 映射或自定义认证，远端写入和转码后续提供。

## 自定义 HTTP/JSON 音乐库

音乐管理 → 音乐库 → 新建音乐库 → 其他音乐 · 自定义 HTTP/JSON，填写名称、服务根地址与 JSON 字段方案。此入口不显示账号或密码，只支持匿名读取；默认方案对应 `data.items` 歌曲数组、`data.total` 总数、`page/size` 分页参数，以及 `id/title/artist/album/duration/url/cover/lyrics` 字段。方案示例和可修改字段见 [HTTP/JSON 来源说明](HTTP_JSON_SOURCES.md)。

完整读取目录后保存，最多 10000 首；所有音乐可选对应分类并搜索，支持同源原始 Range 音频、封面、UTF-8 LRC/纯文本歌词、跨库本地歌单和正常退出队列恢复。服务与媒体地址的协议、主机和端口必须一致，媒体地址不能含查询参数或片段；不自动跟随重定向，不支持认证头、Cookie、签名 URL、跨域 CDN 或脚本转换。

编辑可改名称，根地址、字段方案和来源类型固定；更换这些内容请新建音乐库，避免原歌曲 ID 指向另一份音频。暂时读取错误保留此前完整目录，401/403 单独撤销该来源；删除需确认，仅移除客户端配置，服务端音乐和本地歌单引用保留。连接配置不保存歌曲资源 URL，不缓存音频，服务离线时无法新开播放流。

## 两类歌单与飞牛管理

本地歌单可跨音乐库，保存顺序和来源身份；缺失歌曲保留引用，可重关联。飞牛歌单属于当前账号并写入服务器，网页修改后显式刷新；过期编辑提示核对，不承诺实时推送或并发事务锁。侧栏歌单类别进入管理页，具体歌单进入详情。

管理员可在飞牛素材库与设置中修改支持的选项、扫描和查看后台任务。后台任务必须明确选择；消失、同 ID 身份变化或刷新失败时操作禁用，恢复原任务或明确选择新任务后才能操作。取消/重试成功只表示请求提交，记录消失不代表扫描成功。素材库重关联先检查匹配，结果缺少完成计数时继续显示未确认；重要素材库不应用来做删除试验。

## 配置、升级与错误恢复

默认配置在 `%LOCALAPPDATA%/Melvune.Native/`，与改名前版本的配置分离。关闭旧客户端后备份整个配置目录，再解压新版本到新目录启动；不要覆盖旧包或同时运行两版写入同一配置。本地歌单保存为第 2 版，preview.5 及更早客户端不能读取，回退应同时恢复备份。会话不能复制给其他 Windows 用户使用。

需要独立配置时可运行 `Melvune.App.exe "--data-directory=D:\MelvuneProfile"`，参数必须为绝对目录；连接、索引、歌单、主题与会话均使用该目录。它不会把已有配置自动迁入新目录。

网络失败保留本地来源和已保存数据；检查网络后刷新或重新连接。登录失效需要重新登录。写入超时先刷新核对服务器，不立即重复提交。损坏设置显示失败提示；恢复备份或重新配置，不在程序运行时编辑文件。

## 已知限制和反馈

MP3 远距离首次定位可能读取较多数据；准确模式保持启用。尚未承诺全部编码、DPI/触摸、任意硬件热插拔或长期压力组合。认证式自定义源、脚本转换、跨域 CDN、自定义快捷键、第三方远端写入、转码和自动更新后续添加。本轮 ZIP、便携 EXE、安装 EXE 和 MSI 使用同一份应用内容，最终交付状态见当前清单，旧安装器不自动更新。

集中验证见 [rc.9 用户验证单](RC9_USER_VALIDATION.md)。反馈提供入口（ZIP/便携 EXE）、步骤、预期/实际、版本、格式和错误提示，隐去密码、令牌和私人路径。软件使用 FFmpeg（LGPL 2.1 或更高版本），完整对应源码见 `licenses/corresponding-source/decoder-corresponding-source.zip`；构建与替换方式见 `BUILDING_SOURCES.md`，其他许可见 `licenses/`。

## 桌面联动

设置 → 播放的「SMTC 开关」控制系统媒体联动，默认开启。桌面歌词和本机只读信息接口默认关闭；播放栏右侧的「词」按钮可直接显示/隐藏透明歌词，未锁定时右键歌词可快速调整置顶、锁定、字号和颜色模式。锁定后鼠标点击穿透到后方窗口；托盘菜单可「解锁并找回桌面歌词」，设置页也可解锁。托盘默认开启，关闭到托盘及全局快捷键默认关闭；设置 → 播放还提供 15/30/60/90 分钟睡眠定时。仅主操作按钮和选中控件的背景使用 Windows 强调色；文字、普通图标、滑块和页面保持黑白主题。完整用法见 [桌面联动](DESKTOP_INTEGRATION.md)，独立消费者和接口见 [信息协议](PLAYBACK_INFORMATION_PROTOCOL.md)。

## 音频输出

播放栏的耳机图标与设置 → 播放共用设备列表。设备增删、更新及默认输出变更会自动刷新；选择「系统默认设备」时由 Windows 路由，选择具体设备只改变本应用的输出。完整枚举确认所选设备已断开后，应用尝试回退系统默认；不重新打开歌曲、清空队列或强制恢复暂停。

刷新失败保留上次列表与选择；切换失败恢复已确认的设备，无法确认时明确提示再刷新。自动监视暂不可用时可点「刷新设备」重试。重新连接的设备不会自动抢回输出；需要时再次选择。真正退出会停止监视，收起到托盘则继续。硬件切换可能短暂中断，若驱动已令播放失败请重新播放；不保证所有 USB/蓝牙设备无声隙恢复。

## 音乐管理与关闭行为

侧栏底部仅保留「音乐管理」，标题栏齿轮进入设置。「音乐管理」包含音乐库和歌单分页；本地和飞牛歌单在同一页面管理，飞牛同步歌单以来源图标区分。侧栏默认合并显示全部歌单；在歌单管理页或设置的外观中开启「飞牛歌单单独分组」后按飞牛/其他分类，关闭后合并，任何模式均不隐藏飞牛歌单，偏好在重启后保持。

首次关闭窗口可选择收起到托盘、退出或取消；默认勾选记住选择，未勾选则下次启动重新询问。可在设置更改关闭行为，托盘退出始终结束应用。

SMTC 为 Windows 媒体面板与媒体按键提供播放控制；「允许本机应用读取播放信息与歌词」为适配 Melvune 协议的应用只读提供元数据和歌词，默认关闭，与 SMTC 独立。
