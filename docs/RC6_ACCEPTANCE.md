# rc.6 音乐管理与界面效率验收

2026-10-16。本轮实现统一歌单导航、默认隐藏飞牛歌单及可记忆显示偏好、飞牛来源标志、音乐管理双分页、精简侧栏、明确 SMTC 和第三方只读接口、首次关闭选择和记忆、减少无效刷新。

Debug 应用及测试构建零警告、零错误。集中验证通过：核心120项，队列快照7组/存储8组，窗口927项（管理40、首次关闭37、桌面165、动画22、综合界面663），Node24、发布材料9、便携损坏拒绝14项；隐私扫描 blockerCount=0。证据位于 `.review-audit/rc6-20261016/verification-summary.json` 和对应套件报告。

管理套件覆盖本地/飞牛统一列表、默认隐藏及偏好保存、官方图标实际呈现、来源读写权限、管理页本地与飞牛创建/改名/删除、详情返回、原浏览上下文和音频保持。关闭套件覆盖实际对话框按钮、取消、重入、已有弹窗、旧配置迁移、一次会话选择/记忆、托盘失效、设置同步及最终退出清理。桌面效率检查以实际投递、渲染和属性变更计数证明隐藏100次发布零投递、可见突发100次一次待处理回调、同秒100次时间更新零文字写入。

本轮修复管理层禁用底层侧栏被误判权限、从详情返回管理时的返回循环和底层编辑器禁用阻止前台创建的问题；原有综合验证按新标题宽度和分页可见性更新，保留实际几何/无写入断言。新界面与飞牛操作使用受控协议夹具，不替代真实服务兼容或听音验收。

独立 rc.6 ZIP 与便携 EXE 正在生成，最终版本/来源/摘要、实际 Release 操作及数据保持验收完成后补充收据。包内文档为打包时快照。

WinUI 本身使用 [Visual layer 硬件加速](https://learn.microsoft.com/en-us/windows/apps/develop/composition/visual-layer)。现有动画使用位移、缩放及透明度等 [独立动画](https://learn.microsoft.com/en-us/windows/apps/develop/performance/optimize-animations-and-media)，没有新增假开关或强制独显。本次减少 UI 调度/文字写入工作量，未据此宣称固定帧数或实测 GPU/FPS 提升。更多显卡、DPI、听音及真实第三方服务兼容仍待外部验收。
