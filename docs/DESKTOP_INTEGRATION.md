# rc.2 桌面播放联动

「设置 → 播放 → 桌面播放联动 → SMTC 开关」控制 Windows 媒体联动，默认开启；关闭只移除系统媒体会话，不停止应用内播放。开启后在系统支持的媒体控件中可查看歌曲、歌手、专辑和封面，播放/暂停、上一首/下一首和定位复用应用播放队列。拖动进度条时，对外仍报告实际播放位置；释放并实际定位后再更新。系统控件的外观和是否提供定位由 Windows 决定。

点击播放栏右侧、音频输出按钮前的「词」按钮，或在「设置 → 播放 → 桌面播放联动」打开桌面歌词。它默认关闭，采用透明背景；可拖动歌词窗口、置顶、锁定、调节字号，或选择跟随主窗口/浅色/深色。未锁定时右键歌词可快速设置置顶、锁定、字号、颜色模式和隐藏。锁定后鼠标点击穿透到后方窗口，歌词窗口不再接受点击、拖动或右键；可在系统托盘菜单选择「解锁并找回桌面歌词」，或在「设置 → 播放」关闭「锁定并穿透鼠标」/点击「解锁并找回歌词窗口」。窗口宽度通过右键菜单调整。隐藏歌词不停止歌曲，再次点击「词」按钮可显示；应用内歌词页也使用同一按钮，选中背景表示桌面歌词已开启。断开显示器后窗口位置会限制在最近屏幕工作区。位置、字号、主题、置顶和显示偏好随当前配置目录保存。

系统托盘默认开启，图标可能位于 Windows 的隐藏图标区域。双击打开主窗口；右键菜单提供播放/暂停、上一首/下一首、歌词显示/隐藏、锁定后的解锁找回，以及「退出飞牛音乐」。设置 → 播放 → 桌面常驻可关闭托盘，并选择「关闭窗口时收起到托盘」（默认关闭）。启用后点窗口关闭仅隐藏主窗口，播放、歌词、接口和定时继续；从托盘选择退出才结束应用。托盘不可用时不会将窗口隐藏。系统 Explorer 重建后应用会重新添加图标。

同一设置页的全局快捷键默认关闭。开启后：`Ctrl + Alt + 空格` 播放/暂停，`Ctrl + Alt + ← / →` 上一首/下一首，`Ctrl + Alt + L` 显示/隐藏桌面歌词，`Ctrl + Alt + U` 解锁并找回歌词。已被其他应用占用的组合会在设置中提示，其余可用组合继续工作；关闭开关或退出会释放注册。当前提供固定组合，自定义键位后续添加。

设置 → 播放 → 睡眠定时可选择 15/30/60/90 分钟，开始或取消；再次开始会替换旧定时。剩余时间在此显示，暂停、切歌和收起到托盘时继续计时，到期只停止播放一次，不退出应用或关闭 Windows。定时只属于本次运行会话，重启不会恢复。

有时间轴歌词显示实际播放位置的当前行；纯文本歌词可以滚动查看，无歌词或加载中有明确提示。很长的纯文本桌面预览显示前 12,000 字符，提示限制；不改变应用内完整歌词。外部接口最多导出 2,000 行，每行最多 2,048 字符并标记限制。

本机只读接口默认关闭。在同一设置页开启后，同一 Windows 用户的程序可读取歌曲信息及歌词。接口不提供播放控制，不开放网络端口，不输出 NAS 地址、账户、认证信息、文件完整路径或来源内部 ID。第三方软件必须按 [协议](PLAYBACK_INFORMATION_PROTOCOL.md) 接入；开启接口不能使所有软件自动兼容。

默认发现目录为 `%LOCALAPPDATA%/FnMusic.Native/playback-information/`；便携 EXE 为便携 Data 目录的同名子目录；指定 `--data-directory=<绝对目录>` 时随该目录。发现文件只含版本、随机实例 ID 和管道名。多个运行实例独立注册；关闭接口/正常退出只移除自身注册。强制结束进程可能保留旧记录，客户端应跳过不能连接的记录。

独立 .NET 示例消费者随包位于 `examples/InfoClient/`。从终端运行：

```powershell
./examples/InfoClient/FnMusic.InfoClient.exe list
./examples/InfoClient/FnMusic.InfoClient.exe snapshot
./examples/InfoClient/FnMusic.InfoClient.exe lyrics --offset 0 --limit 32
./examples/InfoClient/FnMusic.InfoClient.exe subscribe --count 5
```

消费者输出真实跨进程读取结果；歌词通过有界分页读取，订阅有背压和写超时。配置、发现和用户音频不属于公开发行材料。封面只用有界本机字节提供给 Windows，不传认证 URL。

退出飞牛账号时，仍有效的本地播放和歌词继续；失效的飞牛播放清理。主窗口退出释放歌词窗口、系统媒体桥和接口。可选功能不会触发自动播放。
