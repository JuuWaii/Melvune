# rc.2 桌面播放联动

Windows 媒体信息随当前播放器工作；在系统支持的媒体控件中可查看歌曲、歌手、专辑和封面，播放/暂停、上一首/下一首和定位复用应用播放队列。拖动进度条时，对外仍报告实际播放位置；释放并实际定位后再更新。系统控件的外观和是否提供定位由 Windows 决定。

在主窗口「设置 → 播放 → 桌面播放联动」打开桌面歌词。它默认关闭，可拖动标题栏、置顶、锁定、调节字号，或选择跟随主窗口/浅色/深色。锁定会隐藏操作栏；在主窗口关闭锁定或点击「解锁并找回歌词窗口」恢复操作。关闭歌词窗口仅隐藏，不停止歌曲；重新开启开关可再次显示。断开显示器后窗口位置会限制在最近屏幕工作区。位置、字号、主题、置顶和显示偏好随当前配置目录保存。

有时间轴歌词显示实际播放位置的当前行；纯文本歌词可以滚动查看，无歌词或加载中有明确提示。很长的纯文本桌面预览显示前 12,000 字符，提示限制；不改变应用内完整歌词。外部接口最多导出 2,000 行，每行最多 2,048 字符并标记限制。

本机只读接口默认关闭。在同一设置页开启后，同一 Windows 用户的程序可读取歌曲信息及歌词。接口不提供播放控制，不开放网络端口，不输出 NAS 地址、账户、认证信息、文件完整路径或来源内部 ID。第三方软件必须按 [协议](PLAYBACK_INFORMATION_PROTOCOL.md) 接入；开启接口不能使所有软件自动兼容。

默认发现目录为 `%LOCALAPPDATA%/FnMusic.Native/playback-information/`；便携 EXE 为便携 Data 目录的同名子目录；指定 `--data-directory=<绝对目录>` 时随该目录。发现文件只含版本、随机实例 ID 和管道名。多个运行实例独立注册；关闭接口/正常退出只移除自身注册。强制结束进程可能保留旧记录，客户端应跳过不能连接的记录。

独立 .NET 示例消费者随包位于 `examples/InfoClient/`。从终端运行：

```powershell
./examples/InfoClient/FnMusic.InfoClient.exe list
./examples/InfoClient/FnMusic.InfoClient.exe snapshot
./examples/InfoClient/FnMusic.InfoClient.exe lyrics --offset 0 --limit 32
./examples/InfoClient/FnMusic.InfoClient.exe subscribe --count 5
```

消费者输出真实跨进程读取结果；歌词通过有界分页读取，订阅有背压和写超时。配置、发现和用户音频不属于公开发行材料。封面只用有界本机字节提供给 Windows，不传认证 URL。

退出飞牛账号时，仍有效的本地播放和歌词继续；失效的飞牛播放清理。主窗口退出释放歌词窗口、系统媒体桥和接口。可选功能不会触发自动播放。

本候选版未签名，自动更新、托盘、全局快捷键、第三方音乐服务和更多 DPI/长期压力组合延期。真实操作的通过范围以 [验收记录](RC2_ACCEPTANCE.md) 为准。
