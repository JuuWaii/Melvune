# 本地歌曲启动索引

2026-10-06。针对“每次打开都要等待扫描”增加持久化本地歌曲索引。已扫描音乐库保存后，重启先从本机索引恢复曲名、歌手、专辑、时长和原曲目标识，注册真实播放来源；后台再枚举目录，核对文件大小与 UTC 修改时间，未变文件复用上次元数据，新文件和变化文件重新读取，已删除文件从新快照移除。

首次建立索引仍需一次扫描。缓存仅保存曲目信息，不复制音频；网络盘离线时可保留列表，播放仍要求原文件可访问。修改时间和大小相同的外部内容改写不保证识别，缓存不作为音频内容校验。后台扫描仍需枚举目录，当前阶段不引入文件系统监控器。

## 存储与更新

- 正常配置目录下 `local-index/<来源ID>.json` 按音乐库隔离，绑定来源与标准化目录。不匹配、损坏、未知版本或超限文档自动视为缓存未命中，不改写原音乐与库配置。
- 加载索引不访问音乐目录、不读取每首文件属性；仅在播放、歌词、封面等实际文件访问时沿用普通路径检查。曲目路径必须相对且位于对应目录内，拒绝路径逃逸、重复文件、备用数据流和不支持扩展名。
- 上限每库 10000 首、文档 32 MiB；通过自有临时文件和原子替换写入完整结果。取消或扫描失败不写入部分扫描结果。
- 正常启动恢复已缓存库，并启动独立于页面导航的后台检查。本地页、所有音乐与本地歌单来源恢复也可使用索引；首次扫描、导入、手动扫描和目录重关联完成后保存新索引。
- 同一目录的后台更新原子替换来源内部快照，不注销播放路由，保留当前播放、队列和歌词/封面请求所属来源。目录重关联、删除或新的手动扫描优先于较早后台结果；后台不能将旧目录结果写回新库。
- 可见歌曲列表在后台完成后更新，保留仍存在的选中项和滚动位置；加载过程中暂缓更新，当前加载结束后应用。标题栏共用活动动画，扫描可取消，失败时提示保留缓存。
- 合成回归默认禁用此自动功能，专用 Debug 参数启用独立 `synthetic-settings`；Release 不含测试入口。发布校验拒绝包内出现本机歌曲索引或飞牛元数据目录。
