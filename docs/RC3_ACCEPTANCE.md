# rc.3 统一候选交付与验收

日期：2026-10-14。本轮目标为统一 Windows x64 ZIP 与便携 EXE，应用版本 0.2.0-rc.3。完整安装器、签名、自动更新及远端发布后置；旧 rc.1、rc.2 产物保留。

当前版本整合本地和飞牛音乐、两类歌单、歌曲右键菜单、应用内封面/歌词/右侧队列/黑白主题，以及 SMTC、透明桌面歌词及锁定穿透、托盘、固定全局快捷键、睡眠定时、设备自动监视和只读信息接口。Navidrome、Emby 与 Subsonic 只读来源共用播放、封面、歌词、跨库本地歌单和正常关闭后单曲续播。通用 Subsonic 按专辑目录读取，最多 10000 首，不承诺任意 REST 服务或未归专辑曲目。

审查发现所有音乐在等待飞牛请求时，第三方账号撤销会使旧来源 revision 失效后直接返回，保留旧歌曲及读取中提示。修复改为最后一个异步步骤完成后重新汇总当前第三方完整目录；不会发布异步读取前的失效快照，也不启动无限重试。本地后台刷新仅保留仍注册的可浏览来源，避免撤销歌曲重新进入及来源计数错误。新增实际 WinUI 401/403 与慢请求交错验证，结果待集中回归。

应用标题与设置文本、程序版本、用户指南、发布说明及打包校验统一至 rc.3。ZIP 校验额外核对 EXE/DLL 与来源记录一致；便携入口通过 PortableOnly 构建，不下载或调用 WiX，也不复用旧安装器版本。独立校验器检查尾部长度/哈希、ZIP CRC、文件路径/内容、来源元数据和摘要完整性。候选 CI 仅构建产物，不自动创建 Release；本轮未运行远端作业。

集中验证：Debug 应用/测试零警告、零错误；核心 120/120，窗口 328/328 通过（来源撤销 18、Subsonic 45、Navidrome 20、Emby 25、桌面/设备/主题 152、六个独立续播进程 68）。Navidrome/Subsonic 八组、Emby 十组协议/存储及续播存储专项通过。新增便携完整性 14 项、Node 24 项和发布材料 9 项通过；源码隐私扫描 blockerCount 为 0。报告位于 `.review-audit/rc3-20261014/`，使用隔离配置和受控音频，不写入真实账号或服务。

最终 Release 构建、便携实际解包/启动及交付哈希在 C05/C06 完成后填入。真实第三方服务、实际听音、硬件、更多 DPI 和安装器图形流程保持用户验证边界。用户集中验证见 RC3_USER_VALIDATION.md；功能延期与唯一进度见 NEXT_DEVELOPMENT_CHECKLIST.md。
