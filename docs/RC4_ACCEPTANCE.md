# rc.4 自定义音乐源交付与验收

日期：2026-10-15。目标为 `0.2.0-rc.4` Windows x64 完整 ZIP 与便携 EXE。本轮来源实现、集中回归、最终打包与隔离实际运行已完成；真实第三方服务兼容性仍按用户验证单验收。唯一进度见 [当前开发清单](NEXT_DEVELOPMENT_CHECKLIST.md)。rc.3 历史保留在 [此前验收](RC3_ACCEPTANCE.md)。

新增来源使用匿名 GET 和已知 JSON 字段方案，提供受控完整分页、最多 10000 首目录、同源原始 Range 音频、封面和 UTF-8 文本歌词。名称、根地址和方案保存为独立来源，歌曲媒体 URL 仅在内存中保存。音乐库动态字段、来源分类/搜索、跨库本地歌单和正常退出单曲续播沿用已有界面。更换地址或映射必须新建来源；删除仅移除客户端连接，保留服务端音乐和歌单引用。

集中验证已通过：Debug 应用与测试构建零警告、零错误，核心 120 项；HTTP/JSON 协议与连接存储各 6 组、Navidrome/Subsonic 8 组、Emby 协议与连接 10 组及续播存储专项通过。受控 WinUI 窗口 1022 项通过（HTTP/JSON 31、来源撤销 18、Subsonic 45、Navidrome 20、Emby 25、桌面与设备 152、六个独立续播进程 68、综合界面 663）。Node 24 项、发布材料 9 项、便携损坏拒绝 14 项通过，源码与历史隐私扫描 blockerCount 为 0；证据在 `.review-audit/httpjson-20261014/`。综合界面附加检查 663 项已通过，涵盖本次新增来源字段、音乐库编辑、封面与歌词页面、队列、主题、导航及动画。字段方案编辑测试改为等待 TextChanged 更新，并比较解析后的方案而非 TextBox 换行格式；设备按钮断言同步为包含当前设备名称的无障碍标签。存储专项验证实际提交前后取消；窗口已提交后不二次读取检查另行验证。受控夹具不代替真实第三方服务器、听音、硬件和全部 DPI/编码组合验收。
