# 0.2.0-rc.2 用户验证单

仅使用 rc.2 独立目录或安装包。rc.1 保留用于回退。建议先复制已有个人配置作为用户自管备份，停止旧播放器后再启动新版本。便携 EXE 复用旁边 Data；常规安装复用当前用户配置。程序和安装器未签名。

- 本地和飞牛各播放一首：确认声音、暂停/恢复、切歌、进度定位和停止；应用内歌词与队列仍正确。
- Navidrome 首版 ZIP：在音乐库管理中新建连接，检查全部歌曲/搜索/原始播放/跳转/封面/歌词。新建混合本地与 Navidrome 的本地歌单，重启后身份保持；飞牛注销不影响其播放。编辑名称和密码、删除取消与确认、错误密码/断网后刷新分别验证；删除连接后歌单引用应保留为不可用。真实服务 URL 子路径、Range 行为、版本及反向代理兼容性尚需此项验证。
- 使用本应用的 Windows 媒体卡片或媒体键：确认标题/歌手/封面、播放状态、上一首/下一首；如系统提供时间轴，验证定位。确保一次媒体命令只执行一次。
- 主界面和应用内歌词页：点击音频输出按钮前的「词」按钮显示/隐藏透明桌面歌词；拖动歌词窗口，右键调节置顶、锁定、字号和颜色；锁定后点击后方窗口应直接生效，通过设置页解锁并找回；关闭歌词确认音频继续，按钮与设置页状态同步。设置 → 播放的「SMTC 开关」可单独关闭系统媒体联动。
- 有时间轴/纯文本/无歌词分别试用；拖动但未释放进度条时歌词不提前跳到预览位置。
- 系统托盘：右键检查播放、歌词和解锁菜单，双击恢复主窗口。开启关闭到托盘后点窗口关闭，确认歌曲和歌词继续；从托盘退出后图标与歌词均消失。关闭托盘时，关闭窗口仍退出。
- 全局快捷键默认关闭；开启后在其他应用前台使用 Ctrl + Alt + 空格 / 左右箭头 / L / U，验证播放、切歌、歌词开关与解锁。被占用的组合应有明确提示，关闭后不再响应。
- 睡眠定时：开始、取消、替换，查看剩余时间；切歌和收起到托盘后继续计时，到期停止播放一次。重新开始播放不应再次被旧定时停止，重启不恢复旧定时。
- 音频输出：用本应用设备菜单选择耳机/音箱，刷新不应改变选择或重开歌曲；暂停时刷新与切换不应自动续播。拔出所选 USB/蓝牙设备，检查自动回退提示、队列和位置；重新连接后仍保留默认输出，按需重新选择。处于默认输出时改变 Windows 默认设备，应用仍保持默认选择。收起到托盘后再插拔也应刷新。设备异常时观察失败提示，全部设备断开后的驱动恢复和实际声音需硬件验证。
- 开启只读信息接口，运行包内独立消费者，确认歌曲/状态/歌词随切歌更新；关闭接口后连接断开，本实例发现记录消失；重开后可再次连接。
- 歌曲播放中关闭主窗口：歌词窗口消失、系统状态清理、接口退出；重启后偏好和位置恢复，可选功能不自动播放。
- 飞牛退出或失效时，仍有效的本地播放继续。多显示器移除后使用找回按钮，窗口可见可操作。
- 安装版升级时检查自选目录、快捷方式和版本；卸载后用户配置保留。安装器目录选择的实际图形流程仍需用户检查。

反馈请记录入口（ZIP/便携 EXE/setup EXE/MSI）、具体步骤、预期和实际行为。不要提供密码、令牌、完整私人目录或未经脱敏的服务日志。
