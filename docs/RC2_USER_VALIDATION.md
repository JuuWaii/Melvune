# 0.2.0-rc.2 用户验证单

仅使用 rc.2 独立目录或安装包。rc.1 保留用于回退。建议先复制已有个人配置作为用户自管备份，停止旧播放器后再启动新版本。便携 EXE 复用旁边 Data；常规安装复用当前用户配置。程序和安装器未签名。

- 本地和飞牛各播放一首：确认声音、暂停/恢复、切歌、进度定位和停止；应用内歌词与队列仍正确。
- 使用本应用的 Windows 媒体卡片或媒体键：确认标题/歌手/封面、播放状态、上一首/下一首；如系统提供时间轴，验证定位。确保一次媒体命令只执行一次。
- 主界面和应用内歌词页：点击音频输出按钮前的「词」按钮显示/隐藏透明桌面歌词；拖动歌词窗口，右键调节置顶、锁定/解锁、字号和颜色；关闭歌词确认音频继续，按钮与设置页状态同步。设置 → 播放的「SMTC 开关」可单独关闭系统媒体联动。
- 有时间轴/纯文本/无歌词分别试用；拖动但未释放进度条时歌词不提前跳到预览位置。
- 开启只读信息接口，运行包内独立消费者，确认歌曲/状态/歌词随切歌更新；关闭接口后连接断开，本实例发现记录消失；重开后可再次连接。
- 歌曲播放中关闭主窗口：歌词窗口消失、系统状态清理、接口退出；重启后偏好和位置恢复，可选功能不自动播放。
- 飞牛退出或失效时，仍有效的本地播放继续。多显示器移除后使用找回按钮，窗口可见可操作。
- 安装版升级时检查自选目录、快捷方式和版本；卸载后用户配置保留。安装器目录选择的实际图形流程仍需用户检查。

反馈请记录入口（ZIP/便携 EXE/setup EXE/MSI）、具体步骤、预期和实际行为。不要提供密码、令牌、完整私人目录或未经脱敏的服务日志。
