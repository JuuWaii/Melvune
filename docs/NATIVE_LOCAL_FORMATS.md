# 本地格式验收

2026-09-30。Debug 参数 `--verify-local-formats` 用本机现有 FFmpeg 工具生成 12 秒音频，经过正式 LocalMusicSource、Windows 元数据读取和 NativeMusicPlayer，静音验证播放推进、跳转到 7 秒后继续推进、停止释放。生成器不包含在 Release；不读取用户音乐或登录信息。

报告写到运行目录 `local-format-verification.json`，包含格式、完成阶段、异常类型、标签/时长结果及清理结果，不含本地路径。运行前构建 Debug，将现有 FFmpeg 工具放入 PATH，然后从输出目录运行 `FnMusic.App.exe --verify-local-formats`。每种格式设置 45 秒取消期限；生成文件只在随机命名的自有目录中创建，结束时逐文件清理。

| 格式 | 播放/跳转/停止 | Windows 标题、歌手、专辑 | 最终时长 |
| --- | --- | --- | --- |
| WAV | 通过 | 本样本未读取 | 通过 |
| FLAC、MP3、OGG、OPUS、M4A、WMA | 通过 | 本样本均读取 | 通过 |
| AAC | 通过 | 本样本未读取 | 通过 |
| AIFF、AIF | 通过 | 本样本未读取 | FFmpeg 回退后通过 |
| APE | 未验证 | 未验证 | 未验证 |

首次检查发现本机 Windows 属性接口未返回 AIFF/AIF 时长，虽然实际播放和跳转成功。现已增加仅在 Windows 时长缺失或读取失败时的 FFmpeg 时长回退，保留已有 Windows 标签。Windows 读取与解码探测各有 3 秒取消期限；探测复用禁止外部协议的流解码路径，结束时释放输入和解码器。扫描已有的增量缓存也缓存回退结果，未变化文件不重复探测。

修复后十种格式全部完成，时长均处于生成样本预期范围；损坏 AIFF 回退和预取消检查通过，临时文件清理成功。时长回退不宣称补齐缺失标题或专辑；无标签仍按文件名显示。播放位置推进不等于听音或采样级定位精度；每种扩展名仅一个生成样本，尚不覆盖全部编码变体、嵌入封面、损坏媒体矩阵、真实大目录标签耗时和完整文件夹导入交互。APE 没有生成样本，继续保持未验证。

本次代码修改不改变固定 preview.4 交付目录；需要后续交付包才能包含 AIFF 时长修复。

修复后 Debug/Release 构建零警告、零错误；123 项窗口状态回归全部通过（报告阶段 complete，无失败），隐私扫描通过。

## 内嵌封面补充

2026-09-30 扩展同一验证器：向 FLAC、MP3、M4A 样本嵌入 PNG，通过主界面共用的 LocalArtworkReader 读取，并使用 Windows 图片解码器展开像素。测试图片名不匹配任何旁置封面候选，避免把目录中的 PNG 当成内嵌封面结果。

初次检查 FLAC/M4A 成功，MP3 的 Windows 缩略图读取没有返回图片。现已在 Windows 没有图片或处理器失败后，使用受限 FFmpeg 流探测并提取内嵌封面；保持旁置封面优先，不允许媒体内容自行访问外部文件或网络，3 秒探测取消期限、4 MiB 返回数据上限，完成后清理解码器与流。

修复后这三种格式均通过实际像素解码，十种音频仍完成播放/跳转/停止。损坏文件返回无封面、预取消正确抛出取消、测试文件清理均通过。其他格式的内嵌封面仍未验证，不能将这三个样本推广为任意封面编码与容器变体均兼容。
